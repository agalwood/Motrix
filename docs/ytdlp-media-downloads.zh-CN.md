# yt-dlp 媒体下载

Motrix 可以借助 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 把视频站点（YouTube、
Vimeo、bilibili 等数百个站点）的链接解析成真实的流地址，再交给 Motrix 自有的
下载引擎下载。如果配置了 FFmpeg，独立的视频流和音频流会自动合并为一个文件。

## 系统要求

- 包含此功能的 Motrix 版本。
- yt-dlp 可执行文件：可以放在 `PATH` 中，也可以在设置里指定路径。
- FFmpeg 为可选但推荐：没有它时，Motrix 会退而下载最佳的单个渐进式流，而不是
  合并最高的视频流与音频流。

## 启用与配置

打开 **设置 → 集成 → yt-dlp 媒体提取器**：

- **用 yt-dlp 提取媒体链接** —— 总开关。粘贴的链接指向视频站点时，Motrix 会
  先用 yt-dlp 解析出流地址再下载。其他下载不受影响。
- **yt-dlp 路径** —— 留空则使用 `PATH` 中的 yt-dlp。macOS 用户可能需要填写
  Homebrew 二进制的完整路径，例如 `/opt/homebrew/bin/yt-dlp`。
- **格式选择器** —— 作为 `-f` 传给 yt-dlp。留空表示最佳视频加最佳音频。
- **尝试所有链接** —— 对看起来不像视频页面的链接也运行提取器。会让普通下载
  变慢，默认关闭。当站点的媒体链接无法识别时可以打开。
- **重新检测 yt-dlp** —— 重新运行检测并显示检测到的版本，例如
  `yt-dlp 2026.08.19`。

如果检测结果一直为空，请从
[发布页](https://github.com/yt-dlp/yt-dlp/releases) 下载 yt-dlp 或用包管理器
安装，填写路径后点击 **重新检测 yt-dlp**。

## 下载时发生了什么

1. 你把链接粘贴或拖放到 Motrix 中（或从浏览器扩展发送）。
2. 如果链接的主机是已知媒体站点，或 **尝试所有链接** 已开启，Motrix 会运行
   yt-dlp 把页面解析成直接流地址。
3. 配置了 FFmpeg 时，最佳视频流与音频流会并行下载并合并为一个 MP4/MKV
   任务，运行期间显示为合并任务；没有 FFmpeg 时则直接下载最佳的单个流。

非媒体链接会完全跳过提取器，普通下载的行为与之前完全一致。

## 抓取网页中的视频（浏览器扩展）

本仓库附带的浏览器扩展（`extension/`）包含媒体嗅探器和页内抓取浮层：

1. 构建扩展：`cd extension && pnpm install && pnpm run build:chromium`。
2. 在 Chrome 或 Edge 中以未打包扩展的形式加载 `extension/dist/chromium`
   （Firefox 请使用 `pnpm run build:firefox` 构建），然后在扩展弹窗中与
   桌面应用配对。
3. 在任意页面播放视频。嗅探器检测到后，点击页面上出现的抓取按钮（或打开
   弹窗查看完整列表）。
4. 选择一项即可发送给 Motrix。直接流会立即下载；HLS/DASH 页面和 watch 页面
   URL 会在服务端解析，启用 yt-dlp 时同样走 yt-dlp，与粘贴链接完全一致。
5. 启用 yt-dlp 时，浮层还会列出该页面可选的清晰度：**视频** 区按分辨率各一行
   （如 `1080p`、`720p`），配置了 FFmpeg 时 **音频** 区提供 **MP3** 行。选择
   分辨率会下载不高于该值的最佳流；选择 **MP3** 会下载最佳音频流并转换为
   `.mp3` 文件。视频开始播放时会自动从桌面端获取列表（每分钟最多刷新一次），
   嗅探到的资源行不受影响、照常显示。

浮层只在 `http(s)` 页面的顶层框架中运行，只显示简短的标签（文件名或分辨率）
—— 页面代码永远看不到存储的流地址或 Cookie。

## 故障排查

- **链接下载下来只是一小段 HTML** —— 该站点不在内置媒体站点列表中。请开启
  **尝试所有链接**，或用浏览器扩展的抓取浮层发送正在播放的视频。
- **任务是单个流而不是合并任务** —— 未检测到 FFmpeg。请在
  **设置 → 集成 → 媒体工具** 中配置，然后重新下载。
- **yt-dlp 版本报错** —— 请经常更新 yt-dlp；视频站点变化频繁，旧版提取器容易
  失效。
- **浮层没有清晰度行** —— 桌面端无法列出该页面（yt-dlp 未启用、未找到可执行
  文件，或该站点不在允许列表中）。此时浮层会回退为仅显示嗅探到的资源和"本页
  下载"行；请检查 yt-dlp 设置并确认应用已连接。
