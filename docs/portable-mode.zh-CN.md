# Windows 便携模式

下载并解压 Windows ZIP，在启动前于 `Motrix.exe` 同级创建 `data` 文件夹：

```text
Motrix/
  Motrix.exe
  resources/
  data/
    portable.json
    relocations/
    user-data/
    work/
    tmp/
  Downloads/
```

Motrix 启动时会创建 `data` 内的内容。`Downloads` 是默认下载目录，在需要时创建。
关于窗口会标明便携模式，设置中可以打开当前使用的设置文件。

Windows 安装版和 Microsoft Store 包保持现有行为。包含 `Uninstall Motrix.exe`
的目录视为安装版，即使存在 `data` 文件夹也不会切换。其他平台和开发版本不会自动
启用此模式。

## 数据与系统集成

`data/user-data` 保存设置、任务历史、引擎状态、已安装插件、插件凭据、Chromium
会话数据、日志和崩溃文件。任务工作文件（包括磁力元数据）位于 `data/work`。
Electron、Node 和子进程的临时文件使用 `data/tmp`。

便携模式不会注册或删除开机启动项、文件关联和浏览器 Native Messaging host，
也不支持自动安装 CLI。本地桥接仍可运行，但不会为便携副本安装依赖系统注册的
浏览器启动与发现组件。已有安装版的系统集成保持不变。

便携资料与安装版资料相互独立，不会自动导入当前电脑的设置或旧版数据。便携模式
不能同时设置 `MOTRIX_USER_DATA` 或 `MOTRIX_BRIDGE_DATA_DIR`。`data` 无法读取
或写入时会停止启动，不会回退到 AppData。

## 移动应用

复制应用文件夹或拔出移动硬盘前，请完全退出 Motrix。复制整个文件夹，包括
`data`、`Downloads` 和其中其他下载目录。请保留 `data/portable.json`，它记录
应用先前的位置，并用于恢复中断的位置迁移。迁移前的设置和路径记录保存在
`data/relocations`，重试会从这些原始记录恢复。若在迁移中断期间手动修改了资料，
恢复会停止，而不会覆盖这些修改。

启动时，原应用目录内的路径会调整到当前目录。设置、任务路径、文件列表及嵌套的
恢复记录会在引擎启动前完成更新。URL 和应用目录以外的路径保持原样，自定义插件配置、
高级引擎配置和命令脚本仍需自行管理。旧位置的
引擎快照不会直接重放；应用会使用重定位后的 Motrix 记录，结合既有恢复检查重建
任务。续传仍需要实际的未完成文件、检查点和种子元数据。

移动应用后，目标位于外部目录的未完成任务会停止并显示位置错误，不会被静默重定向
到其他磁盘。请先确认原文件和保存位置，再重试或重新创建任务。中断的文件整理阶段
会保留，并暂停自动整理及磁力元数据清理，等待显式恢复。文件系统身份可能
已经变化，因此未完成的插件文件整理日志会被保留并隔离，等待显式恢复。原本中断后
需要重新添加的媒体任务，不会因启用便携模式而获得额外的续传能力。

请勿将整个 Chromium 会话目录作为缓存删除，其中也包含持久化的浏览器存储。
插件凭据会随资料一同移动，请像保护安装版资料一样保护便携文件夹。

## 更新

便携模式可以检查更新，但不会下载安装版或运行安装程序。请下载新版 Windows ZIP，
完全退出 Motrix，将完整的 `data` 文件夹和便携下载目录复制到新解压的应用目录中。
确认新版正常启动前请保留备份，替换程序文件时不要覆盖或丢弃 `data`。
