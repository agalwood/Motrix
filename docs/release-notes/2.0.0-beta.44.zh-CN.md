# Motrix 2.0.0-beta.44

[English](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.44/docs/release-notes/2.0.0-beta.44.md) | 简体中文

Motrix 2.0.0-beta.44 在签名 macOS 安装包中加入 Safari 桌面引导组件，并改进
升级或切换已安装副本时的注册处理，同时区分下载列表中不可用的指标。Safari
扩展仍独立分发。

## 主要更新

- 下载列表现在区分实际为零的速度、尚未取得的数值与不适用的指标。暂停、
  完成、排队等非传输状态的速度和剩余时间留空；做种保留上传速度，媒体合并
  时清空传输指标。零速度也会正常参与数值排序
  （[#2275](https://github.com/agalwood/Motrix/pull/2275)）。
- macOS 签名会先处理 Safari 辅助程序，再由主程序封装应用，修复 x64 注册
  程序尚未签名导致的失败。完整签名、权限和公证检查仍为发布必需门禁
  （[#2273](https://github.com/agalwood/Motrix/pull/2273)）。
- macOS arm64 和 x64 安装包现已包含 Safari 引导服务、注册程序和 LaunchAgent。
  辅助程序获得所需签名和 App Group 权限后，应用继续通过原有公证与安装包
  验证流程（[#2271](https://github.com/agalwood/Motrix/pull/2271)）。
- 打开已安装的 Motrix 时，会核对当前注册服务是否属于该应用。过期或不匹配
  的注册通过有界重试重新绑定，匹配的服务保持运行。如果 macOS 要求批准后台
  项目，Motrix 会保留待批准状态，不覆盖用户选择
  （[#2271](https://github.com/agalwood/Motrix/pull/2271)）。
- 正在运行的 bridge 拒绝 nonce 请求时，Safari 引导流程在一次请求后结束，
  避免多余的启动尝试和重试；bridge 未运行时仍可进入冷启动流程。面向扩展的
  协议保持兼容，并使用生产 Swift／Rust 适配器进行回归验证
  （[#2271](https://github.com/agalwood/Motrix/pull/2271)）。

## 测试前须知

这是预发布软件。安装前请备份现有 Motrix 应用数据和下载文件。Motrix v1 数据的
迁移路径尚未经过验证，请勿让本 beta 使用您唯一的一份 v1 数据。

条件允许时，请使用独立的操作系统账号、设备或 Docker 数据目录并行测试 v2。

使用 Safari 集成时，请安装或更新签名 macOS 应用，再手动打开目标 Motrix.app
一次，完成引导服务注册。如果 macOS 提示，请批准后台项目。仅下载应用不会
改变注册；打开另一份签名副本可能改变注册归属。请配合单独分发的兼容 Safari
扩展，测试升级后的冷启动和已配对连接恢复。不要通过删除数据库或配对凭据
来修复启动到了旧副本的问题。

自动化安装包检查和 Swift／Rust 集成测试不能替代干净 Mac 上的升级与冷启动验收。

受保护的 Snap 工作流完成后，可使用 `sudo snap install motrix --edge` 安装
严格限制的构建。已跟踪 `latest/edge` 的安装应升级到同一组 beta.44 revision。

## 发布门禁通过后计划提供的下载

| 分发方式 | 架构 | 计划产物 |
|---------|------|---------|
| macOS 13 或更高版本 | `arm64`（Apple Silicon）、`x64`（Intel） | 已签名并公证的 DMG 和 ZIP |
| Windows | `x64` | 未签名 NSIS 安装程序（`.exe`）和 ZIP |
| Linux | `x64`、`arm64` | AppImage、DEB、RPM 和 pacman |
| Flatpak 主程序 | `x86_64`、`aarch64` | `Motrix-2.0.0-beta.44-<arch>.flatpak` |
| Flatpak Native Host companion | `linux/x64`、`linux/arm64` | `Motrix-Native-Host-2.0.0-beta.44-linux-<arch>.tar.gz` |
| Docker Hub / GHCR | `linux/amd64`、`linux/arm64` | 两个仓库中的不可变 `2.0.0-beta.44` 标签 |
| Snap Store | `amd64`、`arm64` | `latest/edge` 上的已验证构建集 |

所有容器门禁通过后，可使用以下带版本镜像：
`docker.io/motrixapp/motrix-server:2.0.0-beta.44` 和
`ghcr.io/agalwood/motrix-server:2.0.0-beta.44`。存储、网络与升级说明请参阅
[Docker Server 部署指南](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.44/docs/docker-server.zh-CN.md)。

## 分发说明

- Flatpak 主程序使用应用 ID `app.motrix.native` 和 `beta` 分支。每次升级需
  下载新包并执行 `flatpak install --user --or-update`；这些单文件包没有配置
  Motrix 更新 remote。使用浏览器集成时，还需单独更新 Native Host companion。
  详见 [Flatpak 指南](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.44/docs/flatpak.zh-CN.md)。
- AppImage 桌面集成仍需主动启用。浏览器冷启动需要单独启用 Native Messaging
  host 并注册 AppImage 路径；使用已保存配对重连还需要兼容的配套 Extension。
- 不提供 Windows `arm64` 和所有 32 位安装包。Windows 安装包未签名，可能触发
  Windows SmartScreen 警告，请仅从已发布的官方 GitHub 预发布版下载。
- Beta 容器标签不可变，也不会更新 `latest`、`stable` 或其他稳定通道浮动标签。
- Snap 安装包使用严格限制。已批准的 `personal-files` interface 仅用于为支持的
  浏览器注册 Native Messaging host manifest。Beta 发布只会更新 `latest/edge`。
