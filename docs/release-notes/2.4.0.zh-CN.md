# Motrix 2.4.0

[English](https://github.com/agalwood/Motrix/blob/main/docs/release-notes/2.4.0.md) | 简体中文

## 相比 2.3.0 的变化

- 在「文件 → 创建种子文件」中选择文件或文件夹，生成 BitTorrent v1 的 `.torrent` 文件。桌面端可以选择本机文件，Server Web UI 则从账号有权读取的服务器下载目录取材，并将种子保存到浏览器。勾选保存后开始做种时，Motrix 会校验并使用原文件做种。
- 群晖 DSM 新增实验性原生 SPK，适用于 DSM 7.2.2-72806 及以上版本的受支持 x86_64 与 ARM64 机型。使用套件中心手动安装，本地管理员共享任务和设置。机型范围见[群晖安装指南](https://github.com/agalwood/Motrix/blob/v2.4.0/packaging/synology/README.zh-CN.md)。
- 修复 Windows 下载完成后移除临时后缀时，文件时间戳变化可能使重命名失败的问题。重试可恢复已验证的隔离文件，并保留发生冲突的文件。
- 正式版工作流分别验证并发布飞牛 fnOS 的 FPK 和群晖 DSM 的 SPK。请从 Release 下载与 NAS 架构匹配的安装包，并校验随附的 SHA-256。
- 桌面端 Electron 更新至 **45.2.3**。

## 升级兼容性

**升级前请备份配置和下载文件。** 捆绑引擎使用 SQLite **schema 6**。
从旧版引擎数据库升级时，请保留完整的升级前备份；旧引擎无法打开 schema 6。
如需降级，应先停止所有引擎，再将验证过的备份恢复到单独路径。
不要通过重置或删除已升级数据库来代替恢复。

从 Motrix v1 迁移的用户应遵循
[迁移指南](https://github.com/agalwood/Motrix/blob/v2.4.0/docs/legacy-migration.zh-CN.md)，
并保留原始配置及引擎数据库备份。

## 下载与更新

桌面安装包支持 macOS 13 及以上、Windows 10 及以上和 Linux，提供原生 x64 与 ARM64
构建，不提供 32 位桌面安装包。官方 macOS 安装包必须经过签名和公证。
Windows NSIS 安装程序和 ZIP 未签名，可能触发 SmartScreen；请使用官方 Release 下载。

正式发布会将 `latest*.yml` 和 `beta*.yml` 更新源同时更新至 2.4.0。
Flatpak 安装包和 Native Host 配套程序仍单独提供下载。Snap 可用性以验证后的 Store
发布为准：先发布至 edge，再将同一组 amd64/arm64 修订依次晋级至 candidate 和 stable。

Server 镜像使用 `docker.io/motrixapp/motrix-server:2.4.0` 和
`ghcr.io/agalwood/motrix-server:2.4.0`。公开镜像通过多平台运行验证后，
`2.4`、`2`、`stable` 和 `latest` 将指向同一已验证摘要。详见
[Docker Server 指南](https://github.com/agalwood/Motrix/blob/v2.4.0/docs/docker-server.zh-CN.md)。
