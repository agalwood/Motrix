# Motrix 2.0.0-beta.49

[English](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.49/docs/release-notes/2.0.0-beta.49.md) | 简体中文

Motrix 2.0.0-beta.49 改进插件安装和运行环境配置，去掉插件安装页卡片阴影，并将 v1 自动迁移引导改为只出现一次。

## 主要改进

- 尚未配置 FFmpeg 时也能安装兼容插件。缺少 FFmpeg 或版本不兼容时，在启用或运行插件时给出说明，安装授权界面的运行环境提示不再阻止安装。签名、清单、权限和宿主版本检查保持有效（[#2368](https://github.com/agalwood/Motrix/pull/2368)）。
- 配置 FFmpeg 并刷新检测后，插件操作可直接使用新环境，无需重启 Motrix。较早的检测结果不会覆盖新的可用状态；迟到的启用检查不会撤销后续停用、更新或卸载。插件开关以宿主状态为准（[#2368](https://github.com/agalwood/Motrix/pull/2368)）。
- 未安装插件的详情页采用无阴影的边框卡片（[#2368](https://github.com/agalwood/Motrix/pull/2368)）。
- 检测到 Motrix v1 后只自动引导迁移一次。即使没有选择导入或跳过就离开页面或关闭应用，后续启动也不会再次自动跳转；仍可从侧栏手动进入迁移助手（[#2368](https://github.com/agalwood/Motrix/pull/2368)）。

## 测试前须知

本版本为预发布软件。安装前请备份现有 Motrix 数据和下载文件；条件允许时，使用独立系统账号、机器或 Docker 数据目录测试 v2。

音视频合并仍是单独安装的可选插件。启用或运行前，请在**设置 → 集成 → 媒体工具**中配置 FFmpeg。安装插件不会授予任意文件访问能力：操作仍需选择输入、确认输出，Web 操作还受 Server 操作员策略约束。这些宿主修复无需更新插件或 SDK。

迁移助手不会自动导入或恢复下载。手动迁移保留原始文件，将选中的任务作为暂停记录导入；Windows 仍不支持导入旧版下载进度。

renderer 恢复仍需手动触发。Windows/Linux 的睡眠、GPU 故障及长时间恢复场景仍待更完整验收。本版本没有新增插件网络对 IPv6 字面量 SOCKS 目标的支持；这类请求仍会直接失败，不回退到直连。

受保护的 Snap 工作流完成后，可用 `sudo snap install motrix --edge` 安装严格沙箱版本。跟随 `latest/edge` 的安装应更新到 beta.49 对应的修订集合。

## 发行说明

- Flatpak 使用应用 ID `app.motrix.native` 和 `beta` 分支。新包通过 `flatpak install --user --or-update` 安装；单个包文件不会配置 Motrix 更新源。Native Host 配套包需要单独更新，详见 [Flatpak 指南](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.49/docs/flatpak.zh-CN.md)。
- AppImage 桌面集成仍由用户选择启用。浏览器冷启动需要单独启用 Native Messaging host 并注册 AppImage 路径；恢复已有配对还需要兼容的 Extension。
- 尚无 Windows `arm64` 或任何 32 位应用包。Windows 包未签名，可能触发 SmartScreen，请从官方公开的 GitHub 预发布页面下载。
- beta 容器标签不可变，不更新 `latest`、`stable` 或其他稳定通道别名。Snap 发布只更新 `latest/edge`。
