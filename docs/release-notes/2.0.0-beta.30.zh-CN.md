# Motrix 2.0.0-beta.30

[English](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.30/docs/release-notes/2.0.0-beta.30.md) | 简体中文

Motrix 2.0.0-beta.30 是一次安全与兼容性更新。本版本修复两项 Fastify
漏洞，约束存在漏洞的间接开发依赖，将桌面 runtime 升级到 Electron 44，
并更新应用及构建工具链。只有在所有受保护发布门禁通过后，本版本才适合
公开分发。

## 安全与兼容性

- Fastify 升级到 `5.12.1`，修复
  [CVE-2026-18504](https://github.com/fastify/fastify/security/advisories/GHSA-w2qp-rph6-63g4)：
  validator 可能接受根层 primitive，但 route 代码收到的却是强制转换后的
  object；同时修复
  [CVE-2026-16732](https://github.com/fastify/fastify/security/advisories/GHSA-3m5p-2c4r-xxw2)：
  数字形式的 `trustProxy` hop count 可能被伪造。Motrix 未使用存在风险的数字
  `trustProxy` 配置，但升级后的版本可避免未来误用形成暴露面。
- 在依赖方版本范围允许时，间接依赖 `qs` 会统一收敛到 `6.16.0`，修复
  [CVE-2026-82562](https://github.com/advisories/GHSA-x5fp-wj9c-mxmx) 和
  [CVE-2026-82417](https://github.com/advisories/GHSA-4mjr-xmp4-gh2g)。这两个
  漏洞仅通过开发工具进入依赖树，不属于 Motrix 的打包 runtime。
- Electron Builder 间接依赖的 `@xmldom/xmldom` 收敛到 `0.8.15`，修复
  [CVE-2026-83610](https://github.com/advisories/GHSA-6gmq-8vp8-gcm6)。
  该 parser 仅由开发期打包工具使用。
- Electron 从 `43.4.0` 升级到 `44.1.1`。Electron 44 要求 macOS 13 或更高
  版本，并且不再提供上游 Linux `armv7l` 和 Windows `ia32` 构建。Motrix
  当前发布矩阵本来就只包含 `x64` 和 `arm64`，因此受支持的 Windows 与
  Linux 产物不变。
- Flatpak 依赖生成器固定到支持 Electron 44 架构集合的上游修订；离线 source
  manifest、发布签名输入、runtime hash、CI image 与打包检查同步更新。
- `@motrix/cli` 升级到 `0.5.0`；Biome、Testing Library、Vitest、Vite、
  i18next、React Router、React Hook Form、Undici、UUID 等直接依赖获得兼容的
  patch 或 minor 更新。仓库现使用 pnpm `11.25.0`。
- MBP1 加密实现升级并精确锁定到已通过独立审查的 `@noble/curves` 与
  `@noble/hashes` `2.4.0` 组合；全部规范向量与协议测试均已重新生成或运行通过。
- 插件夹具现使用 `@motrix/plugin-api` `2.1.0`，覆盖其可持久化 delivery context
  新特性。旧 2.0 source 夹具仍予保留，并使用当前 API 做类型检查以保护源码兼容性。

## 测试前须知

这是预发布软件。安装前请备份现有 Motrix 应用数据和下载文件。Motrix v1 数据的
迁移路径尚未经过验证，请勿让本 beta 使用您唯一的一份 v1 数据。

条件允许时，请使用独立的操作系统账号、设备或 Docker 数据目录并行测试 v2。
请重点检查 Server 请求校验、可信反向代理后的部署、Electron 升级后的桌面启动
与窗口行为、CLI 配对和命令，以及当前插件和 API 2.0 插件的加载。

受保护发布完成后，Snap 测试者可使用
`sudo snap install motrix --edge` 安装严格限制的构建。已跟踪
`latest/edge` 的安装应升级到同一组 beta.30 revision。

## 分发说明

- AppImage 桌面集成需要用户主动启用，且只会写入当前用户的 XDG 数据目录。由于
  Native Messaging host 在挂载镜像之外没有稳定路径，浏览器扩展暂时无法向
  AppImage 安装包转交下载任务。
- Flatpak 单独验证，不由 release tag 发布；GitHub 预发布版会包含它的
  Native Host companion 压缩包。
- 不提供 Windows `arm64` 和所有 32 位安装包。
- Windows 安装包未签名，可能触发 Windows SmartScreen 警告。请仅从已发布的
  官方 GitHub 预发布版下载。
- Beta 容器标签不可变，也不会更新 `latest`、`stable` 或其他稳定通道
  浮动标签。
- Snap 安装包使用严格限制。已批准的 `personal-files` interface 仅用于为支持的
  浏览器注册 Native Messaging host manifest。Beta 发布只会更新
  `latest/edge`，不会把构建晋级到 `candidate` 或 `stable`。
