# Motrix 2.0.0-beta.27

[English](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.27/docs/release-notes/2.0.0-beta.27.md) | 简体中文

Motrix 2.0.0-beta.27 允许受保护的 beta 发布把经过验证的 `amd64` 与
`arm64` Snap 构建发布到 Snap Store，并为 Headless Server 新增 GeoIP
支持，同时改进 aria2 行为、Windows 集成、字体、打包与桌面细节。只有在
所有受保护发布门禁通过后，本版本才适合公开分发。

## 主要改进

- 受保护的稳定版与 beta tag 现在会构建、验证并上传一套完整的双架构
  Snap，再把这些精确 revision 发布到 `latest/edge`。Pull request 与手动
  run 仍只构建不发布；晋级到 `candidate` 或 `stable` 时，仍会复用已验证的
  revision。
- Headless Server 现在提供与 Electron 应用一致的 GeoIP 与 peer 查询，会转发
  GeoIP 事件，关闭时会正确停止 manager，并在启动时输出可复制的 Server URL。
  Add Task 对话框也与桌面端布局和动画保持一致
  （[#1986](https://github.com/agalwood/Motrix/pull/1986)）。
- aria2 runtime 默认值已在新建和现有 profile 之间对齐；BitTorrent 预览与文件
  选择行为也会更稳定地以任务的权威元数据为准
  （[#1982](https://github.com/agalwood/Motrix/pull/1982)）。
- 新建 HTTP 下载现在会使用当前性能配置的连接数，不再固定覆盖为 5 个连接
  （[#1989](https://github.com/agalwood/Motrix/issues/1989)）。
- 文件检查器现在会还原索引暂存区中的单文件种子名称、实时刷新进度，并保持带
  方括号文件名的显示顺序
  （[#1991](https://github.com/agalwood/Motrix/issues/1991)、
  [#1992](https://github.com/agalwood/Motrix/issues/1992)）。
- Info Hash 复制按钮现在只复制原始哈希。选择 SOCKS5 时，不会再向下载引擎发送
  不受支持的代理选项；应用更新与 Tracker 同步仍可使用该代理
  （[#1990](https://github.com/agalwood/Motrix/issues/1990)、
  [#1994](https://github.com/agalwood/Motrix/issues/1994)）。
- 开发运行器已改用 `cross-spawn`，使 Windows 上的 `pnpm start` 可以正确找到并
  启动子命令
  （[#1981](https://github.com/agalwood/Motrix/issues/1981)）。
- Windows 11 默认应用检测现在优先使用 `UserChoiceLatest`；CLI 会刷新 Node
  路径检测；并发的目录选择请求不再重复打开原生对话框
  （[#1967](https://github.com/agalwood/Motrix/pull/1967)、
  [#1973](https://github.com/agalwood/Motrix/pull/1973)）。
- 跨平台字体 fallback 会保留内置 Inter 字体，并根据当前平台与 locale 选择合适的
  原生 CJK 字体
  （[#1972](https://github.com/agalwood/Motrix/pull/1972)）。
- Server 产物现在包含 Motrix license；桌面端会保留窗口标题，并提供 favicon 与
  Apple touch icon
  （[#1983](https://github.com/agalwood/Motrix/pull/1983)）。

## 测试前须知

这是预发布软件。安装前请备份现有 Motrix 应用数据和下载文件。Motrix v1 数据的
迁移路径尚未经过验证，请勿让本 beta 使用您唯一的一份 v1 数据。

条件允许时，请使用独立的操作系统账号、设备或 Docker 数据目录并行测试 v2。请勿仅
依赖本 beta 保存重要下载文件。

受保护发布完成后，Snap 测试者可使用 `sudo snap install motrix --edge`
安装严格限制的构建。请检查普通下载、可移动存储设备与浏览器 Native Messaging
集成是否正常。已跟踪 `latest/edge` 的安装应升级到同一组 beta.27 revision。

## 发布门禁通过后计划提供的下载

| 分发方式 | 架构 | 计划产物 |
|---------|------|---------|
| macOS 12 或更高版本 | `arm64`（Apple Silicon）、`x64`（Intel） | DMG 和 ZIP |
| Windows | `x64` | 未签名 NSIS 安装程序（`.exe`）和 ZIP |
| Linux | `x64`、`arm64` | AppImage、DEB 和 RPM |
| Flatpak Native Host companion | `linux/x64`、`linux/arm64` | `Motrix-Native-Host-2.0.0-beta.27-linux-<arch>.tar.gz` |
| Docker Hub / GHCR | `linux/amd64`、`linux/arm64` | 两个仓库中的不可变 `2.0.0-beta.27` 标签 |
| Snap Store | `amd64`、`arm64` | `latest/edge` 上的已验证构建集 |

所有容器门禁通过后，可使用以下带版本镜像：
`docker.io/motrixapp/motrix-server:2.0.0-beta.27` 和
`ghcr.io/agalwood/motrix-server:2.0.0-beta.27`。存储、网络与升级说明请参阅
[Docker Server 部署指南](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.27/docs/docker-server.zh-CN.md)。

## 分发说明

- AppImage 桌面集成需要用户主动启用，且只会写入当前用户的 XDG 数据目录。由于 Native
  Messaging host 在挂载镜像之外没有稳定路径，浏览器扩展暂时无法向 AppImage
  安装包转交下载任务。
- Flatpak 单独验证，不由 release tag 发布；GitHub 预发布版会包含它的 Native Host
  companion 压缩包。
- 不提供 Windows `arm64` 和所有 32 位安装包。
- Windows 安装包未签名，可能触发 Windows SmartScreen 警告。请仅从已发布的官方
  GitHub 预发布版下载。
- Beta 容器标签不可变，也不会更新 `latest`、`stable` 或其他稳定通道浮动标签。
- Snap 安装包使用严格限制。已批准的 `personal-files` interface 仅用于为支持的
  浏览器注册 Native Messaging host manifest。Beta 发布只会更新 `latest/edge`，不会把
  构建晋级到 `candidate` 或 `stable`。
