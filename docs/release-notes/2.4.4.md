# Motrix 2.4.4

English | [简体中文](https://github.com/agalwood/Motrix/blob/main/docs/release-notes/2.4.4.zh-CN.md)

## Changes since 2.4.3

- Fix engine stalls when adding torrents with many files (#2536). Bundled aria2 **1.37.0-motrix.25** appends output mappings in place and Motrix sends contiguous selections as ranges. The dialog shows submission failures. An uncertain creation retains the reserved task identity for reconciliation after restart.
- Update to **MDXP 0.10.0** and use its download handoff methods and payload schemas.
- Desktop can now negotiate durable direct-download handoffs with a paired extension. Set `MOTRIX_DOWNLOAD_HANDOFF=1` before launching Desktop to accept new operations. Turning it off preserves status and recovery for operations already prepared or committed.
- The desktop task manager records the task before dispatching the engine. A reconnect can retrieve the original task ID after a lost reply. Browser Extension **0.1.24** continues to use the existing submission flow.

## Upgrade compatibility

**Back up your profile and download files before upgrading.** The bundled engine
uses SQLite **schema 6**. When upgrading an older engine database, retain its
complete pre-upgrade backup; older engines cannot open schema 6. Stop all engines
before restoring a verified backup to a separate path for a downgrade. Do not
reset or delete the upgraded database as a substitute for recovery.

Users migrating from Motrix v1 should follow the
[migration guide](https://github.com/agalwood/Motrix/blob/v2.4.4/docs/legacy-migration.md)
and retain the original profile and engine database backups.

## Downloads and updates

Desktop packages support macOS 13 or later, Windows 10 or later, and Linux, with
native x64 and ARM64 builds. No 32-bit desktop packages are provided. Official
macOS packages require signing and notarization. Windows NSIS installers and ZIP
archives are unsigned and may trigger SmartScreen; use official Release downloads.

Stable publication updates both `latest*.yml` and `beta*.yml` feeds to 2.4.4.
Flatpak bundles and Native Host companions remain separate downloads. Snap
availability requires verified Store publication to edge and promotion of the
same amd64/arm64 revisions through candidate to stable.

Server images use `docker.io/motrixapp/motrix-server:2.4.4` and
`ghcr.io/agalwood/motrix-server:2.4.4`. After public multi-platform runtime
verification, `2.4`, `2`, `stable`, and `latest` advance to the same verified digest.
See the [Docker Server guide](https://github.com/agalwood/Motrix/blob/v2.4.4/docs/docker-server.md).
