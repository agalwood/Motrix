# Motrix 2.2.1

[English](https://github.com/agalwood/Motrix/blob/v2.2.1/docs/release-notes/2.2.1.md) | 简体中文

Motrix 2.2.1 修复损坏磁力任务会话导致的启动问题，以及 HTTP 重试时丢失原始请求
上下文或下载进度的问题。

## 相比 2.2.0 的改动

- 磁力任务的种子元数据或下载目录缺失时，不再阻止引擎启动。能找到经过哈希校验的
  应用元数据时尝试恢复；否则先备份引擎数据库，再将受影响任务保留为可移除的错误
  记录。其他正常任务可以启动，反复启动不会重建已删除目录，无关任务历史会保留。
  同时防止已确认的旧元数据历史在恢复后变成多余的 HTTP 任务。
- 对符合条件的失败 HTTP 下载，使用原任务、引擎 GID、输出路径、请求选项、Cookie
  和检查点重试。所需引擎上下文可跨重启保留，包括明确为空的 Cookie 状态。复用已有
  下载数据前，引擎会检查原资源身份；凭据保留在引擎中，不会复制到应用任务记录。
  重启后恢复的失败任务仍需用户明确点击重试；Alt+重试保留编辑新下载请求的参数表单。
- 在退出或重新登录 Web UI、连接失去就绪状态后，丢弃尚未完成的重试可用性查询结果，
  防止旧响应重新打开已清除的对话框，或执行上一个会话的重试请求。
- 捆绑引擎更新至 **aria2 1.37.0-motrix.22**，包含 HTTP 续传契约，以及对异常种子
  分片长度和空输入文件行的处理修复。原生打包检查在六个桌面目标上执行真实引擎的
  续传与会话恢复测试。
- 纳入 Snap 发布恢复流程修复：按包哈希验证并复用已接受的 revision，分别保存各架构
  的上传记录，仅发布完整且验证通过的双架构产物。

Electron 保持 **45.2.1**，`vscode-jsonrpc` 保持 **9.0.3**。

## 升级与重试兼容性

**升级前请备份配置和下载文件。** 新引擎会将 SQLite 数据库升级至 **schema 6**，
并保留包含已提交 WAL 数据的完整升级前备份。旧引擎无法打开 schema 6；如需降级，
请停止所有引擎，将经过验证的升级前备份恢复到独立路径，不要删除或重置已升级的
数据库，也请保留更早升级留下的备份。

原任务 HTTP 续传要求启用 SQLite 持久化、使用支持该能力的引擎，并且任务已保存
历史请求和资源上下文。已经删除的 Cookie 或缺失的历史资源校验信息无法重建。
旧任务以及不支持该能力的自定义引擎，仍可能使用原有的新下载参数表单。资源发生
变化或无法验证时，不会直接拿旧的部分文件继续下载。本版不承诺解决所有网站的
认证问题；[#2426](https://github.com/agalwood/Motrix/issues/2426) 和
[#2488](https://github.com/agalwood/Motrix/issues/2488) 仍保留以等待用户验证。

从 Motrix v1 迁移的用户请阅读
[迁移指南](https://github.com/agalwood/Motrix/blob/v2.2.1/docs/legacy-migration.zh-CN.md)，
并保留原始配置及引擎数据库备份。

## 下载与更新

桌面安装包支持 macOS 13 及以上、Windows 10 及以上和 Linux，提供原生 x64 与
ARM64 构建，不提供 32 位桌面安装包。正式 macOS 安装包要求完成签名和公证。
Windows NSIS 安装包与 ZIP 压缩包未签名，可能触发 SmartScreen，请使用官方 Release 下载。

正式发布会将 `latest*.yml` 和 `beta*.yml` 两组更新源推进至 2.2.1。Flatpak 包和
Native Host 配套组件仍单独提供下载。Snap 需要先通过 Store 的 edge 发布验证，再将
同一组 amd64/arm64 revision 依次晋级 candidate 和 stable 后才可用。

Server 镜像使用 `docker.io/motrixapp/motrix-server:2.2.1` 和
`ghcr.io/agalwood/motrix-server:2.2.1`。通过公开多平台运行验证后，`2.2`、`2`、
`stable`、`latest` 别名会推进至同一已验证摘要。使用方法见
[Docker Server 指南](https://github.com/agalwood/Motrix/blob/v2.2.1/docs/docker-server.zh-CN.md)。
