# Motrix 2.1.0

[English](https://github.com/agalwood/Motrix/blob/v2.1.0/docs/release-notes/2.1.0.md) | 简体中文

Motrix 2.1.0 新增已有 BitTorrent 文件管理、可选的 Windows 便携配置、
HTTP 重试参数编辑和 Linux 原生窗口控件，并改进大型种子处理、迁移和更新。

## 相比 2.0.1 的变化

- 可在桌面端或 Web 界面中移动、定位和校验已有 BitTorrent 文件。通过校验的
  文件可以被接管，同时保留任务 ID 和历史，并可选择恢复做种。接管前会校验
  本地 v1 种子分片；缺失或损坏的数据会被明确报告，不会自动启动修复下载。
  此流程不支持移动正在下载的未完成任务。
- 解压 Windows ZIP 后，在 `Motrix.exe` 同级创建 `data` 文件夹即可启用便携模式。
  配置、插件、工作文件和临时数据随应用保存。移动应用文件夹后，应用管理的
  内部路径会随之调整；涉及外部保存位置的任务需要先确认位置再恢复。
  便携副本使用 ZIP 手动更新，不安装系统集成组件。详见
  [便携模式指南](https://github.com/agalwood/Motrix/blob/v2.1.0/docs/portable-mode.zh-CN.md)。
- 符合条件的失败 HTTP 任务可编辑 URL、请求头、认证、代理和下载选项后重试。
  对话框会创建独立下载，保留原失败任务、未完成文件和检查点。既有自动重试
  仍然可用；对符合条件的失败任务使用 Alt+重试可打开参数表单。
- Linux 使用原生窗口控件，跟随 Electron 支持的桌面按钮布局和主题。
  工具栏和弹出菜单避让原生控件区域，并处理左右布局及全屏切换。
- 桌面端明确使用 64 MiB 的引擎 RPC 请求预算，以支持大型、多文件种子，
  并直接报告协议错误，避免误导性的超时提示。Server 保留其配置的请求预算。
  精简任务列表轮询、缓存文件元数据、仅刷新可见详情，并限制分片图渲染规模，
  减少大型任务的重复处理。
- 迁移含旧代理或不支持参数的旧版任务时给出明确提示。验证与续传使用当前
  下载代理策略，并保留 HTTP 内容验证和已有文件保护。
- macOS 更新安装请求按序处理；应用与临时目录位于不同卷，或无法安全检查
  位置时，提供手动替换方式。符合条件的同卷安装位置不限定于 `/Applications`。
- Liquid Glass 仅用于 macOS 桌面端；空状态 WebGL 延后初始化，优先显示文字
  并允许导航。修复通过局域网 HTTP 打开 Web 界面时插件操作的 ID 生成，
  并改善 Windows 托盘图标。
- Electron 更新至 **45.1.0**，同时更新兼容的界面、表单、路由、国际化及静态
  服务器依赖。`vscode-jsonrpc` 保持 **9.0.3**，内置引擎仍为
  **aria2 1.37.0-motrix.21**。

## 下载与更新

桌面安装包支持 macOS 13 及以上、Windows 10 及以上和 Linux，提供原生 x64
与 ARM64 构建，不提供 32 位桌面安装包。macOS DMG 和 ZIP 已签名并公证。
Windows NSIS 安装程序和 ZIP 压缩包未签名，可能触发 SmartScreen 提示，
请从官方 GitHub Release 下载。

正式发布会将 `latest*.yml` 和 `beta*.yml` 更新通道同步至 2.1.0。
Flatpak 应用包与 Native Host 配套程序仍分别提供下载，详见
[Flatpak 指南](https://github.com/agalwood/Motrix/blob/v2.1.0/docs/flatpak.zh-CN.md)。
Snap 构建先发布到 `latest/edge`，再将同一组经过验证的 amd64 和 arm64
revision 依次提升至 candidate 和 stable。

Server 镜像使用不可变的 `docker.io/motrixapp/motrix-server:2.1.0` 和
`ghcr.io/agalwood/motrix-server:2.1.0` 标签。多平台镜像通过公开运行时验证后，
再将 `2.1`、`2`、`stable` 和 `latest` 别名指向该版本。
详见 [Docker Server 指南](https://github.com/agalwood/Motrix/blob/v2.1.0/docs/docker-server.zh-CN.md)。

升级前请备份配置和下载文件。从 Motrix v1 迁移的用户应按照
[迁移指南](https://github.com/agalwood/Motrix/blob/v2.1.0/docs/legacy-migration.zh-CN.md)
操作，并保留原始配置与引擎数据库备份。

## 已知限制

- 编辑参数后的 HTTP 重试会创建新下载，不提供对保留文件的认证断点续传，
  也不代表已经解决 [#2426](https://github.com/agalwood/Motrix/issues/2426)
  报告的 Windows DNS 或续传失败。
- Windows 便携目录跨真实磁盘移动仍需更广泛的原生验证。请遵循便携模式指南，
  在确认移动后的配置和下载文件正常之前，保留原文件夹。
- Linux 窗口控件取决于 Electron 支持的桌面行为。最终 GNOME 原生复测以及
  KDE Plasma、X11、WhiteSur 覆盖尚未完成；本次未增加应用内的交通灯样式选择器。
- 新增 BT 文件管理对话框已提供英文、简体中文和繁体中文，其他语言的这些
  文案目前使用英文。
