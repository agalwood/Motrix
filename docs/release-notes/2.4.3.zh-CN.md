# Motrix 2.4.3

[English](https://github.com/agalwood/Motrix/blob/main/docs/release-notes/2.4.3.md) | 简体中文

## 相比 2.4.2 的变化

- 支持自定义 Server 访问密码，并保留现有的随机密码和 CLI 管理流程。
- Server 停机期间持续处理退出信号，等待写入及其他清理完成，避免原子文件写入打断正常停机。
- 新增设置，允许在打开任务详情时继续显示下载统计。
- 下载进度显示一位小数，提高活跃任务进度的刷新频率，并合并不同控件发出的重复暂停请求。
- 适配飞牛 fnOS SDK **0.6.0**，改进独立浏览器的目录授权、取消和弹窗处理，为不支持的文件操作提供清晰提示，并支持宿主主题实时同步。原生内嵌页面和移动端继续使用原生文件能力。
- 更新 **Electron 至 45.3.3**、**i18next 至 27.1.3**、**react-i18next 至 18.0.2**，包含异常语言代码处理和翻译资源订阅的修复。
- 将插件调用图升级至 **React Flow 13.0.1**，保持节点选择、拖动、应用主题和原有视图留白。
- 更新 Biome 和 user-event 测试工具，保持 **vscode-jsonrpc 9.0.3** 不变。

## 升级兼容性

**升级前请备份配置和下载文件。** 捆绑引擎使用 SQLite **schema 6**。
从旧版引擎数据库升级时，请保留完整的升级前备份；旧引擎无法打开 schema 6。
如需降级，应先停止所有引擎，再将验证过的备份恢复到单独路径。
不要通过重置或删除已升级数据库来代替恢复。

从 Motrix v1 迁移的用户应遵循
[迁移指南](https://github.com/agalwood/Motrix/blob/v2.4.3/docs/legacy-migration.zh-CN.md)，
并保留原始配置及引擎数据库备份。

## 下载与更新

桌面安装包支持 macOS 13 及以上、Windows 10 及以上和 Linux，提供原生 x64 与 ARM64
构建，不提供 32 位桌面安装包。官方 macOS 安装包必须经过签名和公证。
Windows NSIS 安装程序和 ZIP 未签名，可能触发 SmartScreen；请使用官方 Release 下载。

正式发布会将 `latest*.yml` 和 `beta*.yml` 更新源同时更新至 2.4.3。
Flatpak 安装包和 Native Host 配套程序仍单独提供下载。Snap 可用性以验证后的 Store
发布为准：先发布至 edge，再将同一组 amd64/arm64 修订依次晋级至 candidate 和 stable。

Server 镜像使用 `docker.io/motrixapp/motrix-server:2.4.3` 和
`ghcr.io/agalwood/motrix-server:2.4.3`。公开镜像通过多平台运行验证后，
`2.4`、`2`、`stable` 和 `latest` 将指向同一已验证摘要。详见
[Docker Server 指南](https://github.com/agalwood/Motrix/blob/v2.4.3/docs/docker-server.zh-CN.md)。
