# Motrix 2.0.0-beta.52

[English](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.52/docs/release-notes/2.0.0-beta.52.md) | 简体中文

Motrix 2.0.0-beta.52 新增 Windows ARM64 原生桌面安装包，包含
aria2 1.37.0-motrix.19、文件系统辅助程序和浏览器 Native Host。

## 主要变化

- Windows ARM64 电脑可以使用原生 NSIS 安装包或便携 ZIP。Electron、SQLite、
  aria2 和两个原生辅助程序均使用 ARM64 构建。新引擎已独立发布为
  [aria2 1.37.0-motrix.19](https://github.com/motrixapp/aria2/releases/tag/v1.37.0-motrix.19)。
- Windows x64 下载文件名保持不变，ARM64 安装包和 ZIP 带有明确的 `arm64`
  后缀。两种架构共用 Windows 更新通道，根据正在运行的应用架构选择安装包。
- Windows 原生发布检查覆盖打包后的应用、SQLite、原生辅助程序和 aria2
  WebSocket 通信。引擎发布检查还会在 Windows ARM64 上验证 HTTPS 证书信任、
  长路径、任务 Cookie 和旧版进度恢复。

## 选择 Windows 安装包

| 电脑／应用架构 | 安装程序 | 便携压缩包 |
|---------------|----------|------------|
| x64 | `Motrix-Setup-2.0.0-beta.52.exe` | `Motrix-2.0.0-beta.52-win.zip` |
| ARM64 | `Motrix-Setup-2.0.0-beta.52-arm64.exe` | `Motrix-2.0.0-beta.52-win-arm64.zip` |

在 Windows ARM 仿真环境下运行的现有 x64 安装仍沿用 x64 更新路径。
切换到原生版本前，请备份配置、退出 Motrix，再安装 ARM64 版本。
不要让两种架构的应用同时使用同一份配置。

Windows 安装包均未签名，可能触发 SmartScreen。请从官方 GitHub 预发布版下载。
本版本不提供 32 位桌面安装包。

## 发布门禁通过后的计划下载

| 分发方式 | 架构 | 计划产物 |
|----------|------|----------|
| macOS 13 或更新版本 | `arm64`、`x64` | 已签名并公证的 DMG 和 ZIP |
| Windows | `x64`、`arm64` | 未签名的 NSIS 安装包和 ZIP |
| Linux | `x64`、`arm64` | AppImage、DEB、RPM 和 pacman |
| Flatpak 主程序 | `x86_64`、`aarch64` | 带版本号的 `.flatpak` 安装包 |
| Flatpak Native Host 配套程序 | `linux/x64`、`linux/arm64` | 带版本号的 `.tar.gz` 压缩包 |
| Docker Hub／GHCR | `linux/amd64`、`linux/arm64` | 不可变的 `2.0.0-beta.52` tag |
| Snap Store | `amd64`、`arm64` | `latest/edge` 上通过验证的构建集 |

全部容器门禁通过后，可使用
`docker.io/motrixapp/motrix-server:2.0.0-beta.52` 或
`ghcr.io/agalwood/motrix-server:2.0.0-beta.52`。详见
[Docker Server 指南](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.52/docs/docker-server.zh-CN.md)。
Beta 发布不会更新稳定容器别名。

Snap 用户可通过 `sudo snap install motrix --edge` 安装。Flatpak 单文件包需要
使用 `flatpak install --user --or-update` 手动更新，Native Host 配套程序需单独
更新。详见 [Flatpak 指南](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.52/docs/flatpak.zh-CN.md)。

## 测试前须知

升级前请备份配置和下载文件。旧版迁移仍只导入暂停记录，复用 BitTorrent 数据前
需要明确授权。Windows 恢复要求本地固定 NTFS 卷，并须通过
[迁移指南](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.52/docs/legacy-migration.zh-CN.md)
说明的所有权、路径及权限检查。请保留引擎升级前的 pre-schema5 数据库备份。

真实 Windows SMB 共享上的 Explorer 行为、原生 fnOS 验收以及完整 Chromium
扩展下载提交流程仍不在本次已验证范围内。反馈问题时，请提供操作系统、架构、
安装包类型和复现步骤。
