# Motrix 2.0.0-beta.40

[English](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.40/docs/release-notes/2.0.0-beta.40.md) | 简体中文

Motrix 2.0.0-beta.40 改进 Dashboard 监控与下载操作，将桌面版文件删除默认改为
移入系统废纸篓，并新增经过验证的 Flatpak 主程序包。本版还修复媒体进度、
Server 任务更新、浏览器提供的文件名，以及 NAT socket 生命周期错误。

## 主要更新

- 上传与下载图表保留稳定的折线顶点并连续滚动，传输结束后继续向零速率滚动。
  Dashboard 任务行可直接暂停、继续与重试，并支持减少动态效果偏好
  （[#2176](https://github.com/agalwood/Motrix/pull/2176)）。
- 桌面版删除任务文件时默认移入系统废纸篓，下载设置中可明确选择永久删除。
  Shift 删除会预选删除文件，但仍保留确认对话框；文件清理失败时保留任务与
  种子元数据，便于重试（[#2176](https://github.com/agalwood/Motrix/pull/2176)）。
- 改进 Dashboard 控件、引擎诊断、托盘速度与下载标签。最小窗口下仍能完整
  显示速度列，同时保留自定义列布局；清空选择时关闭对应的任务详情面板
  （[#2168](https://github.com/agalwood/Motrix/pull/2168)、
  [#2174](https://github.com/agalwood/Motrix/pull/2174)、
  [#2175](https://github.com/agalwood/Motrix/pull/2175)、
  [#2176](https://github.com/agalwood/Motrix/pull/2176)）。
- 媒体下载进度按完整分片计划计算，区分下载进度与处理阶段。分片元数据独立于
  任务数据库保存，文件列表展示全部分片；刷新 FFmpeg 支持时无需重启正在
  进行的下载（[#2156](https://github.com/agalwood/Motrix/pull/2156)、
  [#2158](https://github.com/agalwood/Motrix/pull/2158)、
  [#2160](https://github.com/agalwood/Motrix/pull/2160)）。
- 下载源在产生副作用前完成校验。URL 输入保留原始字节，说明格式错误，对
  存在歧义的修正要求确认；浏览器交接下载时保留建议文件名
  （[#2154](https://github.com/agalwood/Motrix/pull/2154)、
  [#2155](https://github.com/agalwood/Motrix/pull/2155)）。
- Server 可恢复任务更新并保留磁力任务的文件选择。共享导航统一处理任务链接
  及已删除任务的通知，Linux 托盘图标支持颜色偏好，NAT 避免 UDP socket
  生命周期导致的崩溃（[#2162](https://github.com/agalwood/Motrix/pull/2162)、
  [#2163](https://github.com/agalwood/Motrix/pull/2163)、
  [#2166](https://github.com/agalwood/Motrix/pull/2166)、
  [#2167](https://github.com/agalwood/Motrix/pull/2167)）。
- 发布流程在公开发布前构建并验证 `x86_64` 与 `aarch64` Flatpak 主程序包。
  浏览器集成使用同一 Release 中单独安装的 Native Host companion
  （[#2172](https://github.com/agalwood/Motrix/pull/2172)）。

## 测试前须知

这是预发布软件。安装前请备份现有 Motrix 应用数据和下载文件。Motrix v1 数据的
迁移路径尚未经过验证，请勿让本 beta 使用您唯一的一份 v1 数据。

条件允许时，请使用独立的操作系统账号、设备或 Docker 数据目录并行测试 v2。
请重点检查下载结束后的速度图表、任务操作、移入废纸篓与永久删除、媒体下载及
处理阶段进度，以及 Server 在连接中断后的恢复。

受保护的 Snap 工作流完成后，可使用 `sudo snap install motrix --edge` 安装
严格限制的构建。已跟踪 `latest/edge` 的安装应升级到同一组 beta.40 revision。

## 发布门禁通过后计划提供的下载

| 分发方式 | 架构 | 计划产物 |
|---------|------|---------|
| macOS 13 或更高版本 | `arm64`（Apple Silicon）、`x64`（Intel） | 已签名并公证的 DMG 和 ZIP |
| Windows | `x64` | 未签名 NSIS 安装程序（`.exe`）和 ZIP |

| Flatpak 主程序 | `x86_64`、`aarch64` | `Motrix-2.0.0-beta.40-<arch>.flatpak` |

所有容器门禁通过后，可使用以下带版本镜像：
`docker.io/motrixapp/motrix-server:2.0.0-beta.40` 和
`ghcr.io/agalwood/motrix-server:2.0.0-beta.40`。存储、网络与升级说明请参阅
[Docker Server 部署指南](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.40/docs/docker-server.zh-CN.md)。

## 分发说明

- Flatpak 主程序使用应用 ID `app.motrix.native` 和 `beta` 分支。每次升级需
  下载新包并执行 `flatpak install --user --or-update`；这些单文件包没有配置
  Motrix 更新 remote。使用浏览器集成时，还需单独更新 Native Host companion。
  详见 [Flatpak 指南](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.40/docs/flatpak.zh-CN.md)。
- AppImage 桌面集成仍需主动启用。浏览器冷启动需要单独启用 Native Messaging
  host 并注册 AppImage 路径；使用已保存配对重连还需要兼容的配套 Extension。
- 不提供 Windows `arm64` 和所有 32 位安装包。Windows 安装包未签名，可能触发
  Windows SmartScreen 警告，请仅从已发布的官方 GitHub 预发布版下载。
- Beta 容器标签不可变，也不会更新 `latest`、`stable` 或其他稳定通道浮动标签。
- Snap 安装包使用严格限制。已批准的 `personal-files` interface 仅用于为支持的
  浏览器注册 Native Messaging host manifest。Beta 发布只会更新 `latest/edge`。
