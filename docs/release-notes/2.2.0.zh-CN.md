# Motrix 2.2.0

[English](https://github.com/agalwood/Motrix/blob/v2.2.0/docs/release-notes/2.2.0.md) | 简体中文

Motrix 2.2.0 恢复可选的桌面下载进度显示，接通 Server 的浏览器扩展媒体下载，
并改进种子元数据校验，同时修复浏览器配置文件连接、Cookie 传递、限速模式
和 Paragon NTFS 下载完成处理。

## 相比 2.1.1 的变化

- 新增 macOS Dock 和 Windows 任务栏下载进度指示，可在外观设置中启用，
  默认关闭。轻量模式释放窗口后仍保留进度，传输结束或关闭选项后清除。
  Linux 和 Web 不启用此选项。
- 切换标准或低速模式时使用所选配置，包括自动切换。低速字段留空时继承
  对应的标准值，自动模式仍受自适应限速约束。
- Server 支持扩展提交的 HLS/DASH 下载和分离音视频合并。扩展重新扫描能力时
  会刷新 FFmpeg 检测，安装或更换可执行文件后无需重启 Server。媒体分片与
  普通任务列表保持分离，并在关闭服务前取消。官方镜像不内置 FFmpeg，
  需要在容器内提供兼容的可执行文件，并在媒体工具设置中确认检测成功。
- 使用同一扩展 ID 的多个浏览器和配置文件可以独立保持连接。下载、重试和
  通知按来源安装实例路由，设置中显示各配置文件状态。已有凭据保持兼容，
  旧任务通知仍可送达，撤销授权仍按扩展授权组生效。
- 在交给引擎前过滤不兼容、过期和重复的浏览器 Cookie，同时保留可用凭据
  及其作用域。完全不兼容或超出容量限制的 Cookie 集合会在创建任务前被拒绝。
  扩展 0.1.22 提供相应的拒绝原因说明，并更安全地处理结果不确定的提交。
- 增加 Safari 配对连续性的后端支持，以持久安装密钥验证变化后的扩展 Origin。
  此能力需要配套的 Safari 扩展更新。对于 Origin 已变化的旧远程配对，
  需要明确输入一次配对码，此后才可持续自动重连。
- 修复 macOS 本地 Paragon NTFS（`ufsd_NTFS`）上的 HTTP/FTP 下载完成后仍保留
  `.motrix` 后缀的问题。既有日志与占位保留流程现在使用稳定的 NTFS 卷身份，
  并正确缓存占位文件身份。此兼容路径仅处理普通文件在同一目录内移除后缀，
  不扩展到任意 NTFS/FUSE 驱动、远程挂载、目录或插件替换。
- 使用 **@motrix/torrent 0.1.1** 替代 `parse-torrent`，提供有边界的元数据解析、
  原始 info-hash 身份、混合种子校验和更安全的文件路径处理。保留上传字节，
  避免不必要的整份缓冲区复制。混合种子使用 v1 swarm；不支持或会改变身份的
  元数据会在进入引擎前被拒绝，包括 Windows 设备名别名。
  **当前引擎仍不支持纯 v2 下载和内容校验。**

Electron 保持 **45.1.0**，`vscode-jsonrpc` 保持 **9.0.3**，内置引擎仍为
**aria2 1.37.0-motrix.21**。

## 下载与更新

桌面安装包支持 macOS 13 及以上、Windows 10 及以上和 Linux，提供原生 x64
与 ARM64 构建，不提供 32 位桌面安装包。macOS DMG 和 ZIP 已签名并公证。
Windows NSIS 安装程序和 ZIP 压缩包未签名，可能触发 SmartScreen 提示，
请使用官方 GitHub Release 下载。

正式发布会将 `latest*.yml` 和 `beta*.yml` 更新通道同步至 2.2.0。
Flatpak 应用包与 Native Host 配套程序仍分别提供下载。Snap 构建先发布到
`latest/edge`，再将同一组经过验证的 amd64 和 arm64 revision 依次提升至
candidate 和 stable。

Server 镜像使用不可变的 `docker.io/motrixapp/motrix-server:2.2.0` 和
`ghcr.io/agalwood/motrix-server:2.2.0` 标签。多平台镜像通过公开运行时验证后，
再将 `2.2`、`2`、`stable` 和 `latest` 别名指向该版本。
详见 [Docker Server 指南](https://github.com/agalwood/Motrix/blob/v2.2.0/docs/docker-server.zh-CN.md)。

升级前请备份配置和下载文件。从 Motrix v1 迁移的用户应按照
[迁移指南](https://github.com/agalwood/Motrix/blob/v2.2.0/docs/legacy-migration.zh-CN.md)
操作，并保留原始配置与引擎数据库备份。

## 配套发布与验证限制

- Chrome／Edge 和 Firefox 扩展 0.1.22 已单独发布。Safari 0.1.22 使用独立的
  签名应用发布流程，已公布的扩展说明仍将 Safari 实机重启验收列为待完成。
  本次 Motrix 提供其所需的后端支持，不代表 Safari 客户端验收或发布已经完成。
  请关注[扩展发布记录](https://github.com/motrixapp/motrix-extension/releases)。
- Windows 任务栏进度已有平台及窗口生命周期自动化覆盖，原生 Windows
  视觉验收仍未完成。
- 58pic.com 的认证下载场景因网站要求人工验证而尚未完成手动验收。
  Cookie 过滤修复不代表所有站点的认证问题都已解决。
