# Motrix 2.0.0-beta.46

English | [简体中文](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.46/docs/release-notes/2.0.0-beta.46.zh-CN.md)

Motrix 2.0.0-beta.46 adds verified one-click FFmpeg installation with a more
compact interface, progress inside the install button, and clearer executable
paths. It includes all updates since beta.44: safe Motrix app links, shutdown
after downloads finish, Hungarian, Safari extension discovery, and download,
NAT, and inspector fixes.

## Highlights

- Media tools can install an official FFmpeg build on supported macOS, Windows,
  and Linux targets. Motrix authenticates the release manifest and validates
  redirects, hashes, archive contents, executable architecture, and platform
  trust requirements before atomically activating it. FFmpeg remains a
  separate, user-initiated download rather than part of the app package
  ([#2299](https://github.com/agalwood/Motrix/pull/2299)).
- Managed FFmpeg installations now live under `binaries/ffmpeg-verified` in
  Motrix's application data directory. The parent directory is created safely
  without overwriting manually installed tools. Detection shows the actual
  executable path; long paths keep their filename visible, with the full path
  available on hover and when copied. The compact, horizontal layout includes
  button progress and a link to the online manual
  ([#2302](https://github.com/agalwood/Motrix/pull/2302)).
- The Downloads footer can shut down the computer once all downloads and
  finalization work finish, with a cancellable 60-second countdown. This opt-in
  action is unavailable in Web, Snap, and Flatpak builds
  ([#2284](https://github.com/agalwood/Motrix/pull/2284)).
- A bounded set of `motrix://` links can navigate to views or prefill a new
  task while still requiring explicit submission. The old `mo://` scheme and
  links that directly control tasks or reveal local paths are retired
  ([#2300](https://github.com/agalwood/Motrix/pull/2300)).
- Hungarian joins the interface languages. Integration now links to the
  separately distributed Safari extension, and translations are improved
  ([#2117](https://github.com/agalwood/Motrix/pull/2117),
  [#2283](https://github.com/agalwood/Motrix/pull/2283)).
- Browser-submitted downloads accept IP addresses, localhost, and local
  hostnames, avoid a synthesized empty `Authorization` header, and preserve
  filenames across cross-origin redirects
  ([#2282](https://github.com/agalwood/Motrix/pull/2282),
  [#2276](https://github.com/agalwood/Motrix/pull/2276),
  [#2295](https://github.com/agalwood/Motrix/pull/2295)).
- Download rows remain reachable while the inspector drawer is open, including
  after compact-layout resizing. Blank toolbar space is draggable only in
  compact layouts, so an empty search can be dismissed in an expanded window
  ([#2288](https://github.com/agalwood/Motrix/pull/2288),
  [#2290](https://github.com/agalwood/Motrix/pull/2290),
  [#2281](https://github.com/agalwood/Motrix/pull/2281)).
- Automatic port mapping accepts valid Unicode router descriptions such as
  Huawei AX3 advertisements ([#2297](https://github.com/agalwood/Motrix/pull/2297)).
- Electron, pnpm, signing dependencies, and security locks are refreshed
  ([#2287](https://github.com/agalwood/Motrix/pull/2287)).

## Before testing

This is prerelease software. Back up existing Motrix application data and
downloads before installing it. Migration from Motrix v1 data has not yet been
validated, so do not use your only copy of v1 data with this beta. When practical,
test v2 using a separate OS account, machine, or Docker data directory.

To install FFmpeg, open Settings → Integration → Media tools. Active plugins
need a Motrix restart to detect a new managed installation. The project manifest
signature does not replace Windows Authenticode; Windows FFmpeg builds may show
SmartScreen warnings. macOS builds must pass Motrix's pinned signing identity
and online notarization checks. See the
[FFmpeg manual](https://motrix.app/manual/ffmpeg/).

Shutdown is a one-time action. Paused, failed, queued, or metadata-pending work
blocks it, and a new task or state change cancels the countdown. Save open work
in other applications before testing it.

After the protected Snap workflow completes, install the strictly confined
build with `sudo snap install motrix --edge`. Installations tracking
`latest/edge` should upgrade to the same beta.46 revision set.

## Distribution notes

- Flatpak bundles use application ID `app.motrix.native` and the `beta` branch.
  Download each new bundle and install it with `flatpak install --user
  --or-update`; these single-file bundles do not configure a Motrix update
  remote. Update the Native Host companion separately for browser integration.
  See the [Flatpak guide](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.46/docs/flatpak.md).
- AppImage desktop integration remains opt-in. Browser cold launch requires
  the separately enabled Native Messaging host and a registered AppImage path;
  reconnecting with a saved pairing also requires a compatible Extension.
- Motrix application packages for Windows `arm64` and all 32-bit targets are
  unavailable. Windows app packages are unsigned and may trigger SmartScreen;
  download them only from the official published GitHub prerelease.
- Beta container tags are immutable and do not update `latest`, `stable`, or
  other stable-channel aliases.
- Snap uses strict confinement. Its approved `personal-files` interface is
  limited to Native Messaging host registration for supported browsers. Beta
  publication updates `latest/edge` only.
