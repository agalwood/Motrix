# Motrix 2.0.0-beta.41

[English](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.41/docs/release-notes/2.0.0-beta.41.md) | 简体中文

Motrix 2.0.0-beta.41 将界面扩展到 25 种语言并支持从右向左布局，改进偏好
设置与桌面通知，并提升下载恢复及本地磁盘、网络文件系统上的文件保存可靠性。

## 主要更新

- 应用现已内置 25 种界面语言，阿拉伯语和波斯语支持从右向左布局。语言选择
  将“跟随系统”置顶，共享对话框、侧边栏控件及下载状态标题均支持本地化。
  Windows 使用原生日语和韩语字体回退
  （[#2211](https://github.com/agalwood/Motrix/pull/2211) 至
  [#2236](https://github.com/agalwood/Motrix/pull/2236)）。
- 偏好设置采用更清晰的布局，新增桌面通知显示选项。下载偏好和目录编辑一起
  保存，GeoIP 修改保留在对话框草稿中，WebSocket 不可用时也能同步已保存的
  设置。启动时保持最大化窗口隐藏，并隐藏外观设置中空的菜单栏区域
  （[#2198](https://github.com/agalwood/Motrix/pull/2198)、
  [#2204](https://github.com/agalwood/Motrix/pull/2204)、
  [#2210](https://github.com/agalwood/Motrix/pull/2210)、
  [#2227](https://github.com/agalwood/Motrix/pull/2227)）。
- 设置采用新的玻璃图标，侧边栏支持自适应配色并默认使用青色，文件列表显示
  列标题与文件类型，滚动条对比度得到改善
  （[#2180](https://github.com/agalwood/Motrix/pull/2180)、
  [#2188](https://github.com/agalwood/Motrix/pull/2188)、
  [#2206](https://github.com/agalwood/Motrix/pull/2206)、
  [#2208](https://github.com/agalwood/Motrix/pull/2208)）。
- 改进 NFS、NTFS 挂载及跨文件系统的下载完成保存过程。最终文件名会经过规范化
  和重名处理，跨设备复制保留时间戳，Windows 临时文件占用冲突会重试，已存在
  的下载卷根目录不再导致目录创建失败
  （[#2179](https://github.com/agalwood/Motrix/pull/2179)、
  [#2192](https://github.com/agalwood/Motrix/pull/2192)、
  [#2205](https://github.com/agalwood/Motrix/pull/2205)、
  [#2219](https://github.com/agalwood/Motrix/pull/2219)）。
- 中断的下载在重试时可从引擎检查点恢复。熔断器处理反复失败的插件 hook，
  内置插件集移除可选的 scraper hook。更新后的 aria2 引擎可打开超过 MAX_PATH
  的 Windows 路径，单文件种子元数据保存在下载目录之外
  （[#2194](https://github.com/agalwood/Motrix/pull/2194)、
  [#2195](https://github.com/agalwood/Motrix/pull/2195)、
  [#2209](https://github.com/agalwood/Motrix/pull/2209)）。
- 打包移除未使用的依赖文件，并按分发类型生成许可证包，同时保留署名信息。
  Electron 升级至 44.4.3，Snap 打包不再声明构建过程未生成的桌面入口
  （[#2188](https://github.com/agalwood/Motrix/pull/2188)、
  [#2191](https://github.com/agalwood/Motrix/pull/2191)）。

## 测试前须知

这是预发布软件。安装前请备份现有 Motrix 应用数据和下载文件。Motrix v1 数据的
迁移路径尚未经过验证，请勿让本 beta 使用您唯一的一份 v1 数据。

条件允许时，请使用独立的操作系统账号、设备或 Docker 数据目录并行测试 v2。
请重点检查语言切换与从右向左布局、通知偏好、中断下载重试、Windows 长路径，
以及保存到网络共享或 NTFS 挂载的下载文件。

受保护的 Snap 工作流完成后，可使用 `sudo snap install motrix --edge` 安装
严格限制的构建。已跟踪 `latest/edge` 的安装应升级到同一组 beta.41 revision。

## 发布门禁通过后计划提供的下载

| 分发方式 | 架构 | 计划产物 |
|---------|------|---------|
| macOS 13 或更高版本 | `arm64`（Apple Silicon）、`x64`（Intel） | 已签名并公证的 DMG 和 ZIP |
| Windows | `x64` | 未签名 NSIS 安装程序（`.exe`）和 ZIP |
| Linux | `x64`、`arm64` | AppImage、DEB、RPM 和 pacman |

所有容器门禁通过后，可使用以下带版本镜像：
`docker.io/motrixapp/motrix-server:2.0.0-beta.41` 和
`ghcr.io/agalwood/motrix-server:2.0.0-beta.41`。存储、网络与升级说明请参阅
[Docker Server 部署指南](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.41/docs/docker-server.zh-CN.md)。

## 分发说明

- Flatpak 主程序使用应用 ID `app.motrix.native` 和 `beta` 分支。每次升级需
  下载新包并执行 `flatpak install --user --or-update`；这些单文件包没有配置
  Motrix 更新 remote。使用浏览器集成时，还需单独更新 Native Host companion。
  详见 [Flatpak 指南](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.41/docs/flatpak.zh-CN.md)。
- AppImage 桌面集成仍需主动启用。浏览器冷启动需要单独启用 Native Messaging
  host 并注册 AppImage 路径；使用已保存配对重连还需要兼容的配套 Extension。
- 不提供 Windows `arm64` 和所有 32 位安装包。Windows 安装包未签名，可能触发
  Windows SmartScreen 警告，请仅从已发布的官方 GitHub 预发布版下载。
- Beta 容器标签不可变，也不会更新 `latest`、`stable` 或其他稳定通道浮动标签。
- Snap 安装包使用严格限制。已批准的 `personal-files` interface 仅用于为支持的
  浏览器注册 Native Messaging host manifest。Beta 发布只会更新 `latest/edge`。
