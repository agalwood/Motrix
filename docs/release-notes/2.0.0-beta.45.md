# Motrix 2.0.0-beta.45

English | [简体中文](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.45/docs/release-notes/2.0.0-beta.45.zh-CN.md)

Motrix 2.0.0-beta.45 adds verified one-click FFmpeg installation, restores a
safe subset of Motrix app links, and can shut down the computer after downloads
finish. It also adds Hungarian, makes the Safari extension easier to discover,
and includes download, NAT, and inspector fixes.

## Highlights

- Media tools can install an official FFmpeg build with one click on supported
  macOS, Windows, and Linux targets. Motrix authenticates the release manifest,
  validates redirects, hashes, archive contents, executable architecture, and
  platform trust requirements before atomically activating it. FFmpeg remains
  a separate, user-initiated download rather than part of the app package
  ([#2299](https://github.com/agalwood/Motrix/pull/2299)).
- The Downloads footer has an opt-in action to shut down the computer once all
  downloads and finalization work finish, with a cancellable 60-second
  countdown. It is unavailable in Web, Snap, and Flatpak builds
  ([#2284](https://github.com/agalwood/Motrix/pull/2284)).
- A bounded set of `motrix://` links can navigate to views or prefill a new
  task while still requiring explicit submission. The old `mo://` scheme and
  links that directly control tasks or reveal local paths are retired
  ([#2300](https://github.com/agalwood/Motrix/pull/2300)).
- Hungarian joins the supported interface languages, and the Integration page
  now links to the separately distributed Safari extension
  ([#2117](https://github.com/agalwood/Motrix/pull/2117),
  [#2283](https://github.com/agalwood/Motrix/pull/2283)).
- Browser-submitted downloads now accept IP addresses, localhost, and local
  hostnames, avoid a synthesized empty `Authorization` header, and preserve
  filenames across cross-origin redirects
  ([#2282](https://github.com/agalwood/Motrix/pull/2282),
  [#2276](https://github.com/agalwood/Motrix/pull/2276),
  [#2295](https://github.com/agalwood/Motrix/pull/2295)).
- Every download row remains reachable while the inspector drawer is open,
  including after compact-layout resizing. Blank toolbar space is draggable
  only in compact layouts, so an empty search can be dismissed normally in an
  expanded window ([#2288](https://github.com/agalwood/Motrix/pull/2288),
  [#2290](https://github.com/agalwood/Motrix/pull/2290),
  [#2281](https://github.com/agalwood/Motrix/pull/2281)).
- Automatic port mapping now accepts valid Unicode router descriptions such as
  Huawei AX3 advertisements ([#2297](https://github.com/agalwood/Motrix/pull/2297)).
- Electron, pnpm, signing dependencies, and security locks are refreshed; both
  dependency trees reported no known vulnerabilities when the update was
  prepared ([#2287](https://github.com/agalwood/Motrix/pull/2287)).

## Before testing

This is prerelease software. Back up existing Motrix application data and
downloads before installing it. Migration from Motrix v1 data has not yet been
validated, so do not use your only copy of v1 data with this beta.

When practical, test v2 in parallel using a separate OS account, machine, or
Docker data directory.

For the managed FFmpeg path, open Settings → Integration → Media tools and use
the install action. Active plugins need a Motrix restart before they detect a
new managed FFmpeg installation. Windows FFmpeg builds are unsigned and may
show SmartScreen warnings; macOS builds must pass Motrix's pinned signing and
online notarization checks.

The shutdown action is deliberately one-time. Paused, failed, queued, or
metadata-pending work blocks it, and a new task or state change cancels the
countdown. Test it only after saving open work in other applications.

After the protected Snap workflow completes, testers can install the strictly
confined build with `sudo snap install motrix --edge`. Existing installations
tracking `latest/edge` should upgrade to the same beta.45 revision set.

## Distribution notes

- Flatpak bundles use application ID `app.motrix.native` and the `beta` branch.
  Download each new bundle and install it with `flatpak install --user
  --or-update`; no Motrix update remote is configured by these single-file
  bundles. Update the Native Host companion separately when using browser
  integration. See the
  [Flatpak guide](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.45/docs/flatpak.md).
- AppImage desktop integration remains opt-in. Browser cold launch requires
  the separately enabled Native Messaging host and a registered AppImage path;
  reconnecting with a saved pairing also requires a compatible Extension.
- Windows `arm64` and all 32-bit packages are unavailable. Windows packages are
  unsigned and may trigger Windows SmartScreen warnings; download them only
  from the official published GitHub prerelease.
- Beta container tags are immutable and do not update `latest`, `stable`, or
  other stable-channel aliases.
- Snap packages use strict confinement. The approved `personal-files`
  interface is limited to Native Messaging host registration for supported
  browsers. Beta publication updates `latest/edge` only.
