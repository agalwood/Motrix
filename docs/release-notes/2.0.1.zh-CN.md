# Motrix 2.0.1

[English](https://github.com/agalwood/Motrix/blob/v2.0.1/docs/release-notes/2.0.1.md) | 简体中文

Motrix 2.0.1 是桌面应用与 Headless Server 的维护版本，改进下载恢复、
桌面稳定性和内存占用，并更新应用及打包依赖。

## 相比 2.0.0 的变化

- 改进 HTTP 续传元数据检查，在跨源重定向及返回原始站点的重定向链中保留
  资源身份。验证失败时提供不泄露敏感信息的诊断原因；无法验证的未完成文件
  仍受保护，不会进行不安全的续传。
- 迁移助手可恢复经过验证的旧版 HTTP 下载，要求原始未完成文件和检查点通过
  支持的恢复检查。导入任务后仍保持暂停，需要用户单独激活。
- 增加连续图形崩溃后的恢复机制，并在外观设置中提供硬件加速控制。
- 限制迁移数据缓存和插件日志占用，释放空闲运行时资源，并改进托盘渲染器清理，
  降低内存使用。
- 内置 aria2 **1.37.0-motrix.21**，包含 select 事件循环的 DNS 定时器恢复修复。
  桌面应用或 Server 异常退出后，由其管理的 aria2 进程会随之停止。
- 原生 Linux 安装包统一使用 `motrix` 作为包名。
- 更新 electron-builder、electron-updater、React Hook Form、i18next、
  react-i18next 和 Biome。插件测试样例统一使用 SDK 2.2.0，格式化命令不再
  改写 Markdown 文档或 YAML 配置。

## 下载与更新

桌面安装包支持 macOS 13 及以上、Windows 10 及以上和 Linux，提供原生 x64
与 ARM64 构建，不提供 32 位桌面安装包。macOS DMG 和 ZIP 已签名并公证。
Windows NSIS 安装程序和 ZIP 压缩包未签名，可能触发 SmartScreen 提示，
请从官方 GitHub Release 下载。

正式发布会将 `latest*.yml` 和 `beta*.yml` 更新通道同步至 2.0.1。
Flatpak 应用包与 Native Host 配套程序仍分别提供下载，详见
[Flatpak 指南](https://github.com/agalwood/Motrix/blob/v2.0.1/docs/flatpak.zh-CN.md)。
Snap 构建先发布到 `latest/edge`，再将同一组经过验证的 amd64 和 arm64
revision 依次提升至 candidate 和 stable。

Server 镜像在 `docker.io/motrixapp/motrix-server` 和
`ghcr.io/agalwood/motrix-server` 使用不可变的 `2.0.1` 标签。
多平台镜像通过公开运行时验证后，才将 `2.0`、`2`、`stable` 和 `latest`
别名指向该版本。

升级前请备份配置和下载文件。从 Motrix v1 迁移的用户应按照
[迁移指南](https://github.com/agalwood/Motrix/blob/v2.0.1/docs/legacy-migration.zh-CN.md)
操作，并保留原始配置与引擎数据库备份。
