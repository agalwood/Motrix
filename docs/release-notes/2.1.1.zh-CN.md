# Motrix 2.1.1

[English](https://github.com/agalwood/Motrix/blob/v2.1.1/docs/release-notes/2.1.1.md) | 简体中文

Motrix 2.1.1 提高可设置的下载并发上限，并修复旧版任务迁移时误报路径冲突的问题。

## 相比 2.1.0 的变化

- 同时下载任务数的设置范围从 1–100 提高至 **1–200**，默认值仍为 **10**。
  保存其他设置或重启应用后，大于 100 的设置值仍会保留。对应
  [#2439](https://github.com/agalwood/Motrix/issues/2439) 中提高上限的需求。
- 尚未解析的旧版磁力任务，其显示名称和输出提示不再被视为实际占用的文件路径。
  多个磁力任务可以正常导入，不再误报路径冲突，也不会因此阻止其他 HTTP 或
  BitTorrent 任务激活。对于确实占用输出路径的任务，已有文件保护保持不变。
  修复 [#2437](https://github.com/agalwood/Motrix/issues/2437)。

## 下载与更新

桌面安装包支持 macOS 13 及以上、Windows 10 及以上和 Linux，提供原生 x64
与 ARM64 构建，不提供 32 位桌面安装包。macOS DMG 和 ZIP 已签名并公证。
Windows NSIS 安装程序和 ZIP 压缩包未签名，可能触发 SmartScreen 提示，
请从官方 GitHub Release 下载。

正式发布会将 `latest*.yml` 和 `beta*.yml` 更新通道同步至 2.1.1。
Flatpak 应用包与 Native Host 配套程序分别提供下载。Snap 构建先发布到
`latest/edge`，再将同一组经过验证的 amd64 和 arm64 revision
依次提升至 candidate 和 stable。

Server 镜像使用不可变的 `docker.io/motrixapp/motrix-server:2.1.1` 和
`ghcr.io/agalwood/motrix-server:2.1.1` 标签。多平台镜像通过公开运行时验证后，
再将 `2.1`、`2`、`stable` 和 `latest` 别名指向该版本。

升级前请备份配置和下载文件。从 Motrix v1 迁移的用户应按照
[迁移指南](https://github.com/agalwood/Motrix/blob/v2.1.1/docs/legacy-migration.zh-CN.md)
操作，并保留原始配置与引擎数据库备份。

## 已知限制

BitTorrent 任务在重启或恢复时进行的哈希校验，仍会占用下载并发名额。
本次提高上限未增加并行哈希校验，也未将校验调度与下载调度分离。
使用默认的 `bt-detach-seed-only=true` 配置时，已经进入做种状态的任务
仍不占下载并发名额。
