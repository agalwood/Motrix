# Motrix 2.0.0-beta.42

English | [简体中文](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.42/docs/release-notes/2.0.0-beta.42.zh-CN.md)

Motrix 2.0.0-beta.42 makes Tracker refreshes and task updates recoverable,
fixes desktop notification delivery and Linux startup guidance, and improves
localized units, download controls, and file completion reliability.

## Highlights

- Tracker subscriptions refresh independently of the download engine, retain
  bounded last-good source snapshots, and expose source, selection, and update
  history details. Supplemental selection uses enabled sources and recent health
  evidence. Existing BT tasks can preview and confirm Tracker changes while
  preserving original and manually added addresses, manual exclusions, and pause
  intent. Interrupted updates can recover; periodic source refreshes do not
  automatically rewrite existing tasks. Private torrents and torrents with
  unknown privacy stay outside public automatic injection
  ([#2269](https://github.com/agalwood/Motrix/pull/2269)).
- Desktop download notifications respect the selected system/in-app display
  mode, including system delivery while Motrix is focused. Foreground completion
  bursts share a success toast. Linux replaces nonfunctional login-startup
  switches with desktop-managed setup guidance and a manual link
  ([#2254](https://github.com/agalwood/Motrix/pull/2254),
  [#2261](https://github.com/agalwood/Motrix/pull/2261)).
- Information units and decimal formatting follow the interface language while
  preserving the selected byte-unit system. Appearance adds a flat Cloud White
  sidebar color. Download column separators align with their boundaries,
  scrollbar tracks reduce content bleed-through, and toolbar window dragging is
  limited to compact headers
  ([#2259](https://github.com/agalwood/Motrix/pull/2259),
  [#2255](https://github.com/agalwood/Motrix/pull/2255),
  [#2247](https://github.com/agalwood/Motrix/pull/2247),
  [#2248](https://github.com/agalwood/Motrix/pull/2248),
  [#2263](https://github.com/agalwood/Motrix/pull/2263)).
- File completion handles temporary Windows sharing conflicts with bounded
  retries, preserves filesystem diagnostics, and distinguishes a completed rename
  from a later directory-sync failure. Duplicate directory flushes are avoided
  when the native helper reports a recognized completion outcome
  ([#2265](https://github.com/agalwood/Motrix/pull/2265)).
- Paired browser clients can discover configured download directories over MDXP.
  Safari Origins are accepted by pairing and identity handling, with a macOS
  native bootstrap foundation. The signed desktop packages do not yet include
  the Swift registrar and launch service required for complete Safari cold-start
  support; the Safari extension is distributed separately
  ([#2244](https://github.com/agalwood/Motrix/pull/2244),
  [#2267](https://github.com/agalwood/Motrix/pull/2267)).
- Windows AppX/MSIX runtime support isolates packaged profiles and delegates
  application updates to the installation source. This release does not add a
  Microsoft Store package. Plugin detail links use the website's current paths,
  and Electron updates to 44.4.5 with matching offline packaging inputs
  ([#2242](https://github.com/agalwood/Motrix/pull/2242),
  [#2268](https://github.com/agalwood/Motrix/pull/2268)).

## Before testing

This is prerelease software. Back up existing Motrix application data and
downloads before installing it. Migration from Motrix v1 data has not yet been
validated, so do not use your only copy of v1 data with this beta.

When practical, test v2 in parallel using a separate OS account, machine, or
Docker data directory. Check Tracker source refreshes and task-change previews, notification modes,
localized units, Linux login startup, and file completion on Windows and network
filesystems.

After the protected Snap workflow completes, testers can install the strictly
confined build with `sudo snap install motrix --edge`. Existing installations
tracking `latest/edge` should upgrade to the same beta.42 revision set.

## Distribution notes

- Flatpak bundles use application ID `app.motrix.native` and the `beta` branch.
  Download each new bundle and install it with `flatpak install --user
  --or-update`; no Motrix update remote is configured by these single-file
  bundles. Update the Native Host companion separately when using browser
  integration. See the
  [Flatpak guide](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.42/docs/flatpak.md).
- AppImage desktop integration remains opt-in. Browser cold launch requires
  the separately enabled Native Messaging host and a registered AppImage path;
  reconnecting with a saved pairing also requires a compatible Extension.
- Windows `arm64` and all 32-bit packages are unavailable. Windows packages are
  unsigned and may trigger Windows SmartScreen warnings; download them only
  from the official published GitHub prerelease.
- Beta container tags are immutable and do not update `latest`, `stable`, or
  other stable-channel aliases.
- Snap packages use strict confinement. The approved `personal-files`
  interface is limited to Native Messaging host registration for supported
  browsers. Beta publication updates `latest/edge` only.
