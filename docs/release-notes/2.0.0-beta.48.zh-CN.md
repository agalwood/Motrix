# Motrix 2.0.0-beta.48

[English](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.48/docs/release-notes/2.0.0-beta.48.md) | 简体中文

Motrix 2.0.0-beta.48 新增声明式插件操作、任务重新下载、手动渲染器恢复、紧凑
桌面布局、持久化限速单位和独立插件代理。本版本还改进下载诊断、登录启动行为、
设置布局与启动反馈。

## 主要更新

- 插件现在可以声明有边界且支持本地化的操作表单，并通过现有 QuickJS 沙箱在
  桌面端和 Server 中运行。由宿主管理的任务支持进度、取消、重连恢复、资源限制
  和绑定到单次调用的文件授权。媒体合并已迁移到这套通用界面；兼容的操作插件
  需要 Motrix `2.0.0-beta.48` 或更高版本
  （[#2350](https://github.com/agalwood/Motrix/pull/2350)）。
- 已完成的普通下载在详情区和上下文菜单中新增“重新下载”。它会复用已保存的
  任务选项，输出路径已有文件时请求确认；按住 Alt 点击可先编辑选项。插件启动
  与可选 hook 的故障相互隔离，不会阻止普通下载完成收尾
  （[#2363](https://github.com/agalwood/Motrix/pull/2363)）。
- 下载仍在主进程中继续时，Motrix 可以发现失败或无响应的渲染器。用户可从恢复
  界面、原生菜单或托盘手动恢复受影响的窗口，无需重启下载引擎。本版本只观察
  渲染器健康状态，尚未启用自动恢复
  （[#2349](https://github.com/agalwood/Motrix/pull/2349)）。
- 仅通过配置使用的 `app.mainWindowMinWidth` 和 `app.mainWindowMinHeight`
  支持紧凑桌面布局，同时保留原有 914 × 672 默认值。下载页、设置页、侧栏和
  独立恢复界面会适配窄窗口；操作系统自身的最小尺寸限制仍可能生效
  （[#2356](https://github.com/agalwood/Motrix/pull/2356)、
  [#2359](https://github.com/agalwood/Motrix/pull/2359)）。
- 上传和下载限速可以分别使用 KB/s 或 MB/s 输入；使用二进制单位时可选择
  KiB/s 和 MiB/s。切换单位会保留精确字节限制，每个字段也会在保存和重启后
  记住所选单位（[#2362](https://github.com/agalwood/Motrix/pull/2362)）。
- 插件目录、安装包、内置插件更新和安全策略请求现在在桌面端与 Server 中使用
  独立的“插件安装与更新”代理用途。网络失败时保留最近一次可用目录，并提供
  脱敏诊断和重试操作（[#2360](https://github.com/agalwood/Motrix/pull/2360)）。
- 生产日志会保留有边界且已脱敏的 aria2 警告与错误细节，包括过去可能被通用
  `No URI available.` 消息掩盖的 HTTP 状态和 aria2 错误码。面向用户的错误
  提示和重试行为没有变化（[#2361](https://github.com/agalwood/Motrix/pull/2361)）。
- Windows 上 Motrix 已运行时，如果关闭了“登录时显示窗口”，重复的登录启动
  会保留当前可见状态；用户明确启动应用时仍会恢复并聚焦窗口
  （[#2348](https://github.com/agalwood/Motrix/pull/2348)）。
- 主渲染器加载时，Mo 启动标志新增遵循减少动态效果偏好的微光动画
  （[#2364](https://github.com/agalwood/Motrix/pull/2364)）。

## 测试前须知

这是预发布软件。安装前请备份现有 Motrix 应用数据和下载文件。条件允许时，
请使用独立的操作系统账号、设备或 Docker 数据目录测试 v2。

本 beta 仅支持手动渲染器恢复。在更广泛的跨平台长时间测试完成前，崩溃或卡死
后的自动恢复保持禁用。Windows 和 Linux 的睡眠、GPU 故障及长时间恢复场景
尚未达到与 macOS 相同的验收覆盖。

声明式操作依赖单独分发的兼容插件。文件访问仍限制在单次插件调用内，Web 操作
还会受到 Server 管理员策略限制。开始操作前，请检查每个申请访问的文件和输出
位置。

插件代理会安全拒绝当前不支持的 IPv6 字面地址 SOCKS 目标，不会回退为直连。
插件目录与安装包主机通常使用域名。本 beta 尚未在 Windows 上手动复验代理行为。

复制的诊断会隐藏签名 URL 查询参数、凭据、敏感请求头和原始请求目标；分享前
仍应检查日志，因为任意插件文本或 URL 路径中仍可能包含敏感数据。

受保护的 Snap 工作流完成后，可使用 `sudo snap install motrix --edge` 安装
严格限制的构建。跟踪 `latest/edge` 的安装应升级到同一组 beta.48 revision。

## 发布门禁通过后计划提供的下载

| 分发方式 | 架构 | 计划产物 |
|---------|------|---------|
| macOS 13 或更高版本 | `arm64`（Apple Silicon）、`x64`（Intel） | 已签名并公证的 DMG 和 ZIP |
| Windows | `x64` | 未签名 NSIS 安装程序（`.exe`）和 ZIP |
| Linux | `x64`、`arm64` | AppImage、DEB、RPM 和 pacman |
| Flatpak 主程序 | `x86_64`、`aarch64` | `Motrix-2.0.0-beta.48-<arch>.flatpak` |
| Flatpak Native Host companion | `linux/x64`、`linux/arm64` | `Motrix-Native-Host-2.0.0-beta.48-linux-<arch>.tar.gz` |
| Docker Hub / GHCR | `linux/amd64`、`linux/arm64` | 两个仓库中的不可变 `2.0.0-beta.48` 标签 |
| Snap Store | `amd64`、`arm64` | `latest/edge` 上的已验证构建集 |

所有容器门禁通过后，可使用
`docker.io/motrixapp/motrix-server:2.0.0-beta.48` 或
`ghcr.io/agalwood/motrix-server:2.0.0-beta.48`。存储、网络与升级说明请参阅
[Docker Server 部署指南](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.48/docs/docker-server.zh-CN.md)。

## 分发说明

- Flatpak 主程序使用应用 ID `app.motrix.native` 和 `beta` 分支。每次升级需
  下载新包并执行 `flatpak install --user --or-update`；这些单文件包不会配置
  Motrix 更新 remote。使用浏览器集成时，还需单独更新 Native Host companion。
  详见 [Flatpak 指南](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.48/docs/flatpak.zh-CN.md)。
- AppImage 桌面集成仍需主动启用。浏览器冷启动需要单独启用 Native Messaging
  host 并注册 AppImage 路径；使用已保存配对重连还需要兼容的配套 Extension。
- 不提供 Windows `arm64` 和所有 32 位应用安装包。Windows 应用安装包未签名，
  可能触发 SmartScreen，请仅从已发布的官方 GitHub 预发布版下载。
- Beta 容器标签不可变，也不会更新 `latest`、`stable` 或其他稳定通道浮动标签。
- Snap 使用严格限制。已批准的 `personal-files` interface 仅用于为支持的浏览器
  注册 Native Messaging host manifest。Beta 发布只会更新 `latest/edge`。
