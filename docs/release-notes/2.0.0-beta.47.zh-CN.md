# Motrix 2.0.0-beta.47

[English](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.47/docs/release-notes/2.0.0-beta.47.md) | 简体中文

Motrix 2.0.0-beta.47 新增桌面端 v1 任务迁移助手、签名官方可选插件安装，以及
手动音视频合并的主程序支持。本版本包含 beta.46 之后的全部更新，改进权限审查、
下载收尾与存储恢复、窗口恢复和诊断日志，并内置 aria2 `1.37.0-motrix.17` 引擎。

## 主要更新

- 桌面端迁移助手可发现 v1 配置或使用指定目录，预览任务并将选中的记录导入为
  暂停状态，保留原文件。支持元数据备份、重复检测、中断恢复、重试和报告导出。
  兼容的 BT 任务可在明确授权目录后，单独验证并启用
  （[#2331](https://github.com/agalwood/Motrix/pull/2331)）。
- 内置 aria2 `1.37.0-motrix.17` 提供原生旧版 checkpoint 导入，以及暂停 BT
  任务的持久恢复。引擎数据库升级至 schema 5 前，会保留完整的 SQLite 升级前
  快照（[#2342](https://github.com/agalwood/Motrix/pull/2342)）。
- 桌面端和 Server 可从插件市场安装签名官方可选插件。Motrix 会验证签名包，
  保留常规权限确认和卸载方式，并在安装前说明不兼容的主程序版本
  （[#2312](https://github.com/agalwood/Motrix/pull/2312)）。
- 配置 FFmpeg 并启用兼容的 `motrix.media-merge` 插件后，可将独立的本地视频
  和音频文件手动合并为 MP4 或 MKV。入口位于插件“操作”页，以及两个已完成
  单文件下载的操作菜单。原文件保留，已有输出文件不会被覆盖。配套插件需单独
  安装，本次主程序发布不内置该插件，也不会自动合并下载
  （[#2308](https://github.com/agalwood/Motrix/pull/2308)）。
- 插件包准备期间直接在安装按钮中显示状态，权限就绪后再打开审查窗口。必需和
  可选权限分组显示，可选权限默认关闭，确认、取消和窗口退出期间保持授权稳定
  （[#2333](https://github.com/agalwood/Motrix/pull/2333)、
  [#2335](https://github.com/agalwood/Motrix/pull/2335)）。
- 改进 macOS exFAT 上的下载后缀移除、实际跨挂载点移动失败，以及存储离线后的
  收尾恢复。离线存储对应的待处理日志得以保留，其他任务可继续恢复；文件已变化
  或状态不明确时，仍保留冲突保护
  （[#2330](https://github.com/agalwood/Motrix/pull/2330)、
  [#2339](https://github.com/agalwood/Motrix/pull/2339)）。
- 保留启动激活并恢复最小化窗口；下载页滚动条保持在列标题下方；macOS 签名版
  恢复下载完成后关机所需的权限；优化生产包和桌面延迟加载
  （[#2325](https://github.com/agalwood/Motrix/pull/2325)、
  [#2323](https://github.com/agalwood/Motrix/pull/2323)、
  [#2337](https://github.com/agalwood/Motrix/pull/2337)、
  [#2316](https://github.com/agalwood/Motrix/pull/2316)）。
- 插件诊断保留普通 URL 查询参数值，同时遮蔽常见凭据名称。关联任务创建日志
  便于检查 URL 改写。详细日志模式一小时后到期，复制日志时使用更严格的脱敏
  （[#2340](https://github.com/agalwood/Motrix/pull/2340)）。
- 已实现签名插件安全策略执行机制，但本版本尚未配置生产信任和签名数据源。
  同步保持休眠，本 beta 不提供实时安全公告阻断
  （[#2326](https://github.com/agalwood/Motrix/pull/2326)）。
- 更新 Electron、pnpm、打包工具、依赖锁文件、GitHub Actions 和回归测试
  （[#2336](https://github.com/agalwood/Motrix/pull/2336)、
  [#2341](https://github.com/agalwood/Motrix/pull/2341)、
  [#2344](https://github.com/agalwood/Motrix/pull/2344)）。

## 测试前须知

这是预发布软件。安装前请备份现有 Motrix 应用数据和下载文件。条件允许时，
请使用独立的操作系统账号、设备或 Docker 数据目录测试 v2。

迁移仅导入记录，不会自动恢复下载。HTTP 任务通过明确的新建下载流程使用独立
目录；BT 原位续传需要兼容的原始元数据、文件选择、引擎支持和明确授权。迁移助手
仅用于桌面端；Windows 会明确拒绝不受支持的旧下载进度导入。请保留 v1 配置和
原文件的备份。旧引擎拒绝 schema 5，因此引擎降级必须使用兼容的升级前数据库快照。

手动音视频合并需要单独发布、签名且兼容 beta.47 的配套插件，以及已配置的
FFmpeg；能否安装取决于该插件的签名发布和 registry 上架。安装 FFmpeg 请打开
“设置 → 集成 → 媒体工具”。正在运行的插件需要重启 Motrix，才能识别新安装的
托管 FFmpeg。详见[FFmpeg 手册](https://motrix.app/zh/manual/ffmpeg/)。

macOS exFAT 收尾兼容路径假设发布期间预留目标名称由应用持有；若外部进程在
验证后替换该预留文件，无法保证原子不覆盖。不支持或状态不明确的文件系统操作
仍会安全拒绝或报告冲突。

复制诊断日志时会遮蔽全部 URL 查询参数值，并省略结构化请求头和正文。分享前
仍需检查日志：插件任意文本或 URL 路径可能包含敏感信息；已写入的详细日志文件
也不会随模式到期而删除。

受保护的 Snap 工作流完成后，可使用 `sudo snap install motrix --edge` 安装
严格限制的构建。已跟踪 `latest/edge` 的安装应升级到同一组 beta.47 revision。

## 发布门禁通过后计划提供的下载

| 分发方式 | 架构 | 计划产物 |
|---------|------|---------|
| macOS 13 或更高版本 | `arm64`（Apple Silicon）、`x64`（Intel） | 已签名并公证的 DMG 和 ZIP |
| Windows | `x64` | 未签名 NSIS 安装程序（`.exe`）和 ZIP |
| Linux | `x64`、`arm64` | AppImage、DEB、RPM 和 pacman |
| Flatpak 主程序 | `x86_64`、`aarch64` | `Motrix-2.0.0-beta.47-<arch>.flatpak` |
| Flatpak Native Host companion | `linux/x64`、`linux/arm64` | `Motrix-Native-Host-2.0.0-beta.47-linux-<arch>.tar.gz` |
| Docker Hub / GHCR | `linux/amd64`、`linux/arm64` | 两个仓库中的不可变 `2.0.0-beta.47` 标签 |
| Snap Store | `amd64`、`arm64` | `latest/edge` 上的已验证构建集 |

所有容器门禁通过后，可使用以下带版本镜像：
`docker.io/motrixapp/motrix-server:2.0.0-beta.47` 或
`ghcr.io/agalwood/motrix-server:2.0.0-beta.47`。存储、网络与升级说明请参阅
[Docker Server 部署指南](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.47/docs/docker-server.zh-CN.md)。

## 分发说明

- Flatpak 主程序使用应用 ID `app.motrix.native` 和 `beta` 分支。每次升级需
  下载新包并执行 `flatpak install --user --or-update`；这些单文件包没有配置
  Motrix 更新 remote。使用浏览器集成时，还需单独更新 Native Host companion。
  详见 [Flatpak 指南](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.47/docs/flatpak.zh-CN.md)。
- AppImage 桌面集成仍需主动启用。浏览器冷启动需要单独启用 Native Messaging
  host 并注册 AppImage 路径；使用已保存配对重连还需要兼容的配套 Extension。
- 不提供 Windows `arm64` 和所有 32 位 Motrix 主程序安装包。Windows 主程序
  安装包未签名，可能触发 SmartScreen，请仅从已发布的官方 GitHub 预发布版下载。
- Beta 容器标签不可变，也不会更新 `latest`、`stable` 或其他稳定通道浮动标签。
- Snap 使用严格限制。已批准的 `personal-files` interface 仅用于为支持的浏览器
  注册 Native Messaging host manifest。Beta 发布只会更新 `latest/edge`。
