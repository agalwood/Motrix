# Motrix 2.0.0-beta.42

[English](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.42/docs/release-notes/2.0.0-beta.42.md) | 简体中文

Motrix 2.0.0-beta.42 改进 Tracker 刷新与任务更新的恢复机制，修复桌面通知
发送和 Linux 启动指引，并改善单位本地化、下载操作及文件完成保存的可靠性。

## 主要更新

- Tracker 订阅独立于下载引擎刷新，在限定时间内保留最近一次有效的来源快照，
  并提供来源、筛选和更新历史详情。补充列表根据已启用来源和近期健康状态筛选。
  现有 BT 任务可先预览再确认 Tracker 变更，保留原始地址、手动添加的地址、
  手动排除记录和暂停意图。中断的更新可以恢复；定期刷新来源不会自动改写现有
  任务。私有种子和隐私状态未知的种子不参与公共 Tracker 自动注入
  （[#2269](https://github.com/agalwood/Motrix/pull/2269)）。
- 桌面下载通知遵循选定的系统／应用内显示模式，Motrix 位于前台时也可发送
  系统通知。前台集中完成的任务共用成功提示。Linux 移除无效的登录启动开关，
  改为桌面环境配置指引与手册链接
  （[#2254](https://github.com/agalwood/Motrix/pull/2254)、
  [#2261](https://github.com/agalwood/Motrix/pull/2261)）。
- 信息单位和小数格式跟随界面语言，同时保留所选字节单位制。外观新增纯色云白
  侧边栏；下载列表分隔线与列边界对齐，滚动条轨道减少内容透出，工具栏窗口
  拖动仅在紧凑标题栏中启用
  （[#2259](https://github.com/agalwood/Motrix/pull/2259)、
  [#2255](https://github.com/agalwood/Motrix/pull/2255)、
  [#2247](https://github.com/agalwood/Motrix/pull/2247)、
  [#2248](https://github.com/agalwood/Motrix/pull/2248)、
  [#2263](https://github.com/agalwood/Motrix/pull/2263)）。
- 下载完成保存时，对 Windows 临时文件占用冲突进行有界重试，保留文件系统
  诊断信息，并区分重命名成功和后续目录同步失败。原生辅助程序报告明确完成
  结果时，避免重复刷新目录
  （[#2265](https://github.com/agalwood/Motrix/pull/2265)）。
- 已配对的浏览器客户端可通过 MDXP 获取配置的下载目录。配对与身份处理支持
  Safari Origin，并新增 macOS 原生引导基础。签名桌面安装包尚未包含完整
  Safari 冷启动所需的 Swift 注册程序和启动服务；Safari 扩展单独分发
  （[#2244](https://github.com/agalwood/Motrix/pull/2244)、
  [#2267](https://github.com/agalwood/Motrix/pull/2267)）。
- Windows AppX／MSIX 运行时支持独立数据目录，并将应用更新交给安装来源管理。
  本版不新增 Microsoft Store 安装包。插件详情链接改用官网当前路径，Electron
  升级至 44.4.5，并同步更新离线打包所需资源
  （[#2242](https://github.com/agalwood/Motrix/pull/2242)、
  [#2268](https://github.com/agalwood/Motrix/pull/2268)）。

## 测试前须知

这是预发布软件。安装前请备份现有 Motrix 应用数据和下载文件。Motrix v1 数据的
迁移路径尚未经过验证，请勿让本 beta 使用您唯一的一份 v1 数据。

条件允许时，请使用独立的操作系统账号、设备或 Docker 数据目录并行测试 v2。
请重点检查 Tracker 来源刷新与任务变更预览、通知模式、单位本地化、Linux
登录启动，以及 Windows 和网络文件系统上的下载完成保存。

受保护的 Snap 工作流完成后，可使用 `sudo snap install motrix --edge` 安装
严格限制的构建。已跟踪 `latest/edge` 的安装应升级到同一组 beta.42 revision。

## 分发说明

- Flatpak 主程序使用应用 ID `app.motrix.native` 和 `beta` 分支。每次升级需
  下载新包并执行 `flatpak install --user --or-update`；这些单文件包没有配置
  Motrix 更新 remote。使用浏览器集成时，还需单独更新 Native Host companion。
  详见 [Flatpak 指南](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.42/docs/flatpak.zh-CN.md)。
- AppImage 桌面集成仍需主动启用。浏览器冷启动需要单独启用 Native Messaging
  host 并注册 AppImage 路径；使用已保存配对重连还需要兼容的配套 Extension。
- 不提供 Windows `arm64` 和所有 32 位安装包。Windows 安装包未签名，可能触发
  Windows SmartScreen 警告，请仅从已发布的官方 GitHub 预发布版下载。
- Beta 容器标签不可变，也不会更新 `latest`、`stable` 或其他稳定通道浮动标签。
- Snap 安装包使用严格限制。已批准的 `personal-files` interface 仅用于为支持的
  浏览器注册 Native Messaging host manifest。Beta 发布只会更新 `latest/edge`。
