# Motrix 2.0.0-beta.38

[English](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.38/docs/release-notes/2.0.0-beta.38.md) | 简体中文

Motrix 2.0.0-beta.38 保留 macOS 菜单栏图标位置，改进 Windows SMB 共享目录的
下载完成处理与恢复，并更新依赖。它也包含原计划在 beta.37 提供的设置和连接状态
提示改进。

Beta.37 已废弃：桌面安装包、更新源和容器的发布流程已在公开发布前取消。
Snap `latest/edge` 已先行收到 beta.37，beta.38 将替代这组构建。
beta.37 标签保持不变。

## 主要改进

- macOS 在正常退出应用以及切换到仅 Dock 的运行模式后，保留用户调整的
  菜单栏图标位置
  （[#2131](https://github.com/agalwood/Motrix/pull/2131)）。
- Windows 下载完成处理支持 SMB 共享目录，包括 UNC 路径和映射盘符。
  恢复流程会重试符合条件的失败记录，同时保留文件身份校验和防止错误替换的保护
  （[#2132](https://github.com/agalwood/Motrix/pull/2132)）。
- 清理后重新安装并更新依赖，包括 Electron 44.3.0、React 19.3、Vite 8.3、
  Vitest 5 和 pnpm 12.4.1。兼容范围内的 Zod 依赖统一版本，Flatpak 源生成
  保留 pnpm 12 锁文件中的两个文档；CI、签名输入和离线打包同步使用固定版本
  与对应校验值。
- 无效设置会显示本地化字段错误并阻止保存。下载、网络、代理、BitTorrent、
  媒体工具和 GeoIP 设置共用校验约束，并保留紧凑的表单布局
  （[#2126](https://github.com/agalwood/Motrix/pull/2126)）。
- 下载设置明确区分连接上限和实际连接数，新增 20／30 个并发下载预设，新设置
  默认使用 10 个并发下载。已有保存值保持不变。自定义值支持 1–100 个并发下载
  和单文件 1–128 个连接
  （[#2126](https://github.com/agalwood/Motrix/pull/2126)）。
- 在用户同意免责协议并保存、且下载引擎就绪后，空白或过期的 Tracker 列表可于
  三秒后同步。Desktop 和 Server 在打开页面或重新连接后仍可显示同步进度
  （[#2126](https://github.com/agalwood/Motrix/pull/2126)）。
- Tracker 来源区分直连与 CDN 地址，新增可选的 animeTrackerList 来源，以及
  默认启用的 CDN 黑名单，同时保留已有来源的选择
  （[#2126](https://github.com/agalwood/Motrix/pull/2126)）。
- NAT 映射不可用时显示中性状态，说明对下载的影响，保留重试次数，并提供重试、
  网络设置和手册入口。本项改进调整状态提示，不改变路由器映射的可用性
  （[#2126](https://github.com/agalwood/Motrix/pull/2126)）。
- 双语 bridge 协议明确规定：应用退出、浏览器重启和发现失败时保留配对，并区分
  应用唤起和首次配对。这是文档澄清，浏览器重连行为取决于配套 Extension 更新
  （[#2129](https://github.com/agalwood/Motrix/pull/2129)）。

## 测试前须知

这是预发布软件。安装前请备份现有 Motrix 应用数据和下载文件。Motrix v1 数据的
迁移路径尚未经过验证，请勿让本 beta 使用您唯一的一份 v1 数据。

条件允许时，请使用独立的操作系统账号、设备或 Docker 数据目录并行测试 v2。
请重点检查无效设置与自定义连接上限、首次同意协议和页面切换后的 Tracker
同步进度、升级后已有 Tracker 来源的选择，以及 NAT 恢复提示。还请检查 macOS
重启或切换运行模式后的托盘位置，以及 Windows SMB 共享目录在重启或短暂断开
后完成下载和恢复任务的表现。

应用退出后的浏览器重连需要兼容的配套 Extension。本 beta 中的 bridge 文档
变更本身不会改变 App 运行时或通信协议。

受保护发布完成后，Snap 测试者可使用
`sudo snap install motrix --edge` 安装严格限制的构建。已跟踪
`latest/edge` 的安装应升级到同一组 beta.38 revision。

## 发布门禁通过后计划提供的下载

| 分发方式 | 架构 | 计划产物 |
|---------|------|---------|
| macOS 13 或更高版本 | `arm64`（Apple Silicon）、`x64`（Intel） | DMG 和 ZIP |
| Windows | `x64` | 未签名 NSIS 安装程序（`.exe`）和 ZIP |
| Linux | `x64`、`arm64` | AppImage、DEB、RPM 和 pacman |
| Flatpak Native Host companion | `linux/x64`、`linux/arm64` | `Motrix-Native-Host-2.0.0-beta.38-linux-<arch>.tar.gz` |
| Docker Hub / GHCR | `linux/amd64`、`linux/arm64` | 两个仓库中的不可变 `2.0.0-beta.38` 标签 |
| Snap Store | `amd64`、`arm64` | `latest/edge` 上的已验证构建集 |

所有容器门禁通过后，可使用以下带版本镜像：
`docker.io/motrixapp/motrix-server:2.0.0-beta.38` 和
`ghcr.io/agalwood/motrix-server:2.0.0-beta.38`。存储、网络、远程 Extension
配对与升级说明请参阅
[Docker Server 部署指南](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.38/docs/docker-server.zh-CN.md)。

## 分发说明

- AppImage 桌面集成仍需主动启用。浏览器冷启动使用单独启用的固定路径 Native
  Messaging host 与已注册的 AppImage 路径；使用已保存配对重连还需要兼容的
  配套 Extension 更新。
- Flatpak 单独验证，不由 release tag 发布；GitHub 预发布版会包含它的 Native
  Host companion 压缩包。
- 不提供 Windows `arm64` 和所有 32 位安装包。
- Windows 安装包未签名，可能触发 Windows SmartScreen 警告。请仅从已发布的
  官方 GitHub 预发布版下载。
- Beta 容器标签不可变，也不会更新 `latest`、`stable` 或其他稳定通道浮动标签。
- Snap 安装包使用严格限制。已批准的 `personal-files` interface 仅用于为支持的
  浏览器注册 Native Messaging host manifest。Beta 发布只会更新
  `latest/edge`，不会把构建晋级到 `candidate` 或 `stable`。
