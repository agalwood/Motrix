# Motrix 2.0.0-beta.39

[English](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.39/docs/release-notes/2.0.0-beta.39.md) | 简体中文

Motrix 2.0.0-beta.39 为 Server 新增目录浏览和应用菜单，改进下载操作与
BitTorrent 做种，并修复磁力任务会话身份冲突时的重启恢复。本版还更新了依赖，
修复 macOS 在关闭主窗口后未恢复“仅菜单栏”模式的问题。

## 主要更新

- Server 可浏览和新建下载目录，支持面包屑、直接编辑路径、键盘导航、排序与
  隐藏目录控制。新建任务和通用设置共用常用目录与最近记录；Desktop 保留系统
  原生目录选择器（[#2144](https://github.com/agalwood/Motrix/pull/2144)）。
- Server 的 Logo 可打开应用菜单，提供设置、任务操作、本地种子文件、帮助和
  Cookie 会话退出登录。种子请求大小上限默认为 8 MiB，可通过
  `MOTRIX_TORRENT_BODY_LIMIT_MIB` 配置为 2–64 MiB，修改后需重启
  （[#2146](https://github.com/agalwood/Motrix/pull/2146)）。
- 下载列表保存排序和列偏好，支持调整队列顺序，并统一选择、键盘操作、紧凑
  菜单、限速控件及可调整大小的任务详情面板。在支持的平台上，点击下载完成
  通知可直接定位下载文件
  （[#2143](https://github.com/agalwood/Motrix/pull/2143)）。
- 做种时间上限设为 `0` 时表示不限时。任务详情保留累计上传量、分享率及实际
  记录的做种时间，支持暂停、重新做种和重启；不会为已有历史补造做种时长
  （[#2143](https://github.com/agalwood/Motrix/pull/2143)）。
- 新建种子任务和已解析的磁力任务直接写入最终路径，完成后就地处理，保留正在
  做种的引擎任务身份。旧临时布局仍可恢复，HTTP／FTP 保留原有临时文件流程
  （[#2139](https://github.com/agalwood/Motrix/pull/2139)）。
- 启动时可恢复符合条件的磁力任务会话身份冲突，保留任务身份、进度与暂停状态。
  会话输入处理避免同时加载 SQLite 和文本会话
  （[#2141](https://github.com/agalwood/Motrix/pull/2141)）。
- macOS 启用“仅菜单栏”模式后，关闭主窗口或按 Cmd+W 会重新隐藏 Dock 图标
  （[#2138](https://github.com/agalwood/Motrix/pull/2138)）。
- 更新 Vitest 5.0.1、React Virtual 3.14.13、Lucide 1.46.0、
  react-i18next 17.0.14、Zod 4.6.5 和 pnpm 12.4.2。锁文件、CI、Docker、
  Snap 与 Flatpak 输入同步使用对应版本和已验证的摘要。

## 测试前须知

这是预发布软件。安装前请备份现有 Motrix 应用数据和下载文件。Motrix v1 数据的
迁移路径尚未经过验证，请勿让本 beta 使用您唯一的一份 v1 数据。

条件允许时，请使用独立的操作系统账号、设备或 Docker 数据目录并行测试 v2。
请重点检查暂停或尚未完成的种子任务在重启后的状态、不限时做种与上传统计、
下载列表偏好的保存，以及 Server 在已配置下载根目录内选择目录的行为。
还请检查 macOS 主窗口关闭后“仅菜单栏”模式的表现。

受保护发布完成后，Snap 测试者可使用 `sudo snap install motrix --edge`
安装严格限制的构建。已跟踪 `latest/edge` 的安装应升级到同一组 beta.39 revision。

## 发布门禁通过后计划提供的下载

| 分发方式 | 架构 | 计划产物 |
|---------|------|---------|
| macOS 13 或更高版本 | `arm64`（Apple Silicon）、`x64`（Intel） | 已签名并公证的 DMG 和 ZIP |
| Windows | `x64` | 未签名 NSIS 安装程序（`.exe`）和 ZIP |
| Linux | `x64`、`arm64` | AppImage、DEB、RPM 和 pacman |
| Flatpak Native Host companion | `linux/x64`、`linux/arm64` | `Motrix-Native-Host-2.0.0-beta.39-linux-<arch>.tar.gz` |
| Docker Hub / GHCR | `linux/amd64`、`linux/arm64` | 两个仓库中的不可变 `2.0.0-beta.39` 标签 |
| Snap Store | `amd64`、`arm64` | `latest/edge` 上的已验证构建集 |

所有容器门禁通过后，可使用以下带版本镜像：
`docker.io/motrixapp/motrix-server:2.0.0-beta.39` 和
`ghcr.io/agalwood/motrix-server:2.0.0-beta.39`。存储、目录浏览、种子大小上限、
网络与升级说明请参阅
[Docker Server 部署指南](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.39/docs/docker-server.zh-CN.md)。

## 分发说明

- AppImage 桌面集成仍需主动启用。浏览器冷启动需要单独启用 Native Messaging
  host 并注册 AppImage 路径；使用已保存配对重连还需要兼容的配套 Extension。
- Flatpak 单独验证，不由 release tag 发布；GitHub 预发布版会包含它的 Native
  Host companion 压缩包。
- 不提供 Windows `arm64` 和所有 32 位安装包。
- Windows 安装包未签名，可能触发 Windows SmartScreen 警告。请仅从已发布的
  官方 GitHub 预发布版下载。
- Beta 容器标签不可变，也不会更新 `latest`、`stable` 或其他稳定通道浮动标签。
- Snap 安装包使用严格限制。已批准的 `personal-files` interface 仅用于为支持的
  浏览器注册 Native Messaging host manifest。Beta 发布只会更新 `latest/edge`。
