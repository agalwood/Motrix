# Motrix 2.0.0-beta.50

[English](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.50/docs/release-notes/2.0.0-beta.50.md) | 简体中文

Motrix 2.0.0-beta.50 新增任务实时活动曲线与历史导航，改进种子和下载交互，并提升配置恢复、插件诊断及会话保存的可靠性。

## 主要改进

- 任务活动页分别展示下载与上传曲线，增加历史概览、范围选择、缩放和键盘导航。下载中及做种任务默认跟随最近 60 秒，已完成任务默认展示完整历史。查看历史时，新样本不会改变已选范围；已完成历史在重启后保持不变（[#2387](https://github.com/agalwood/Motrix/pull/2387)）。
- 将 `.torrent` 文件拖入应用窗口即可打开已填入文件的新建任务界面。拖入操作会检查登录状态和会话变化。下载列表恢复复选框，方便触屏选择；打开文件失败时提供更明确的说明（[#2374](https://github.com/agalwood/Motrix/pull/2374)、[#2377](https://github.com/agalwood/Motrix/pull/2377)、[#2381](https://github.com/agalwood/Motrix/pull/2381)、[#2370](https://github.com/agalwood/Motrix/pull/2370)）。
- **设置 → 高级**展示当前配置文件路径。桌面端可在文件夹中定位配置文件，Server Web 可复制路径。恢复默认配置前先备份损坏文件，备份失败时不替换原文件。长路径统一采用中间省略显示，复制和文件操作仍使用完整值（[#2382](https://github.com/agalwood/Motrix/pull/2382)、[#2384](https://github.com/agalwood/Motrix/pull/2384)）。
- 插件错误写入持久日志，重启 Motrix 后仍可查看。停用插件后移除其任务菜单操作，事件订阅可可靠清理，切换操作格式时不再闪烁（[#2380](https://github.com/agalwood/Motrix/pull/2380)、[#2376](https://github.com/agalwood/Motrix/pull/2376)）。
- 媒体下载、Server 保存目录准备及旧任务重新下载可直接使用已有磁盘根目录，避免重复创建目录。空引擎 ID 以数据库 `NULL` 保存，升级时修复已有空值，避免唯一性约束错误中断任务保存（[#2383](https://github.com/agalwood/Motrix/pull/2383)、[#2386](https://github.com/agalwood/Motrix/pull/2386)）。
- 在迁移界面选择**暂时不用**后，侧栏入口在重启后也保持隐藏；仍可从**设置 → 高级**进入迁移。设置卡片与启动遮罩的视觉反馈也有所调整（[#2378](https://github.com/agalwood/Motrix/pull/2378)）。
- 切换语言时保留引擎重启提示和待重启状态。退出清理期间迟到的激活事件不会重新打开窗口，也不会短暂显示 renderer 恢复界面（[#2385](https://github.com/agalwood/Motrix/pull/2385)、[#2391](https://github.com/agalwood/Motrix/pull/2391)）。

## 测试前须知

本版本为预发布软件。安装前请备份现有 Motrix 数据和下载文件；条件允许时，使用独立系统账号、机器或 Docker 数据目录测试 v2。

迁移助手不会自动导入或恢复下载。手动迁移保留原始文件，将选中的任务作为暂停记录导入；Windows 仍不支持导入旧版下载进度。

持久插件日志无法补回旧版本未写入磁盘的错误。本次扩展的磁盘根目录下载路径仍待 Windows 实机端到端验证。renderer 恢复仍需手动触发，Windows/Linux 的睡眠、GPU 故障及长时间恢复场景仍待更完整验收。

受保护的 Snap 工作流完成后，可用 `sudo snap install motrix --edge` 安装严格沙箱版本。跟随 `latest/edge` 的安装应更新到 beta.50 对应的修订集合。

| 发行形式 | 架构 | 计划产物 |

| macOS 13 及以上 | `arm64`（Apple Silicon）、`x64`（Intel） | 已签名并公证的 DMG 和 ZIP |

容器门禁全部通过后，使用 `docker.io/motrixapp/motrix-server:2.0.0-beta.50` 或 `ghcr.io/agalwood/motrix-server:2.0.0-beta.50`。存储、网络和升级说明见 [Docker Server 指南](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.50/docs/docker-server.zh-CN.md)。

## 发行说明

- Flatpak 使用应用 ID `app.motrix.native` 和 `beta` 分支。新包通过 `flatpak install --user --or-update` 安装；单个包文件不会配置 Motrix 更新源。Native Host 配套包需要单独更新，详见 [Flatpak 指南](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.50/docs/flatpak.zh-CN.md)。
- AppImage 桌面集成仍由用户选择启用。浏览器冷启动需要单独启用 Native Messaging host 并注册 AppImage 路径；恢复已有配对还需要兼容的 Extension。
- 尚无 Windows `arm64` 或任何 32 位应用包。Windows 包未签名，可能触发 SmartScreen，请从官方公开的 GitHub 预发布页面下载。
- beta 容器标签不可变，不更新 `latest`、`stable` 或其他稳定通道别名。Snap 发布只更新 `latest/edge`。
