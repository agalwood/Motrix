# Motrix 2.4.8

[English](https://github.com/agalwood/Motrix/blob/main/docs/release-notes/2.4.8.md) | 简体中文

## 相比 2.4.7 的变化

- **内置引擎升级至 aria2 1.37.0-motrix.27（#2421、#2575）**：在运行期通过 `aria2.changeGlobalOption` 切换 `async-dns` 时立即清空内存 `DNSCache`；在 `checkAddrconfig()` 中跳过未启用网卡（`IfOperStatusUp` / `IFF_UP`）并过滤不可路由的 IPv6 地址（保留合法 ULA 与全球单播 IPv6），避免双栈环境持续命中断网 IPv6 导致下载零速度。
- **不可达路由自动 DNS 回退（#2421、#2572）**：`auto` DNS 模式下遇到不可达路由错误（Windows `WSAENETUNREACH` / `WSAEHOSTUNREACH` 与 POSIX `Network is unreachable` / `No route to host`）时自动回退系统 DNS，并将对应错误细化为 `NetworkError`。
- **直连磁力元数据接力命名与落盘修复（#2569、#2571）**：在直连磁力任务完成元数据 `followedBy` 接力后立即解析真实种子名称与落盘路径，修复任务标题停留在 `infoHash` 以及完成时报错的问题。
- **群晖 DSM 7 目录身份校验修复（#2557、#2568）**：在不支持真实 `birthtimeNs` 的群晖 DSM 7 文件系统上不再回退使用 `ctime`，修复暂停或删除任务时误报 `Task download directory changed` 的问题。
- **桌面端符号链接下载目录落盘修复（#2562、#2570）**：在桌面端落盘前对包含符号链接的 `saveDir` 进行规范化解析，修复下载目标位于软链目录时完成报错的问题。
- **媒体下载失败默认清理临时目录（#2532、#2573）**：媒体任务下载失败时默认清理 `%TEMP%/motrix-media` 下的临时分片目录，避免反复失败在系统盘堆积数 GB 残留文件（如需调试保留可显式设置 `MOTRIX_KEEP_FAILED_MEDIA_TMP=1`）。

## 升级兼容性

**升级前请备份配置和下载文件。** 捆绑引擎使用 SQLite **schema 6**。
从旧版引擎数据库升级时，请保留完整的升级前备份；旧引擎无法打开 schema 6。
如需降级，应先停止所有引擎，再将验证过的备份恢复到单独路径。
不要通过重置或删除已升级数据库来代替恢复。

从 Motrix v1 迁移的用户应遵循
[迁移指南](https://github.com/agalwood/Motrix/blob/v2.4.8/docs/legacy-migration.zh-CN.md)，
并保留原始配置及引擎数据库备份。

## 下载与更新

桌面安装包支持 macOS 13 及以上、Windows 10 及以上和 Linux，提供原生 x64 与 ARM64
构建，不提供 32 位桌面安装包。官方 macOS 安装包必须经过签名和公证。
Windows NSIS 安装程序和 ZIP 未签名，可能触发 SmartScreen；请使用官方 Release 下载。

正式发布会将 `latest*.yml` 和 `beta*.yml` 更新源同时更新至 2.4.8。
Flatpak 安装包和 Native Host 配套程序仍单独提供下载。Snap 可用性以验证后的 Store
发布为准：先发布至 edge，再将同一组 amd64/arm64 修订依次晋级至 candidate 和 stable。

Server 镜像使用 `docker.io/motrixapp/motrix-server:2.4.8` 和
`ghcr.io/agalwood/motrix-server:2.4.8`。公开镜像通过多平台运行验证后，
`2.4`、`2`、`stable` 和 `latest` 将指向同一已验证摘要。详见
[Docker Server 指南](https://github.com/agalwood/Motrix/blob/v2.4.8/docs/docker-server.zh-CN.md)。
