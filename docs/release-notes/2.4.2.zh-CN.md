# Motrix 2.4.2

[English](https://github.com/agalwood/Motrix/blob/main/docs/release-notes/2.4.2.md) | 简体中文

## 相比 2.4.1 的变化

- 删除任务时，同一数据库事务会取消其未完成的文件整理恢复。启动时也会清理旧版遗留的孤立恢复记录，避免已删除任务再次触发文件整理。
- 更新桌面运行时至 **Electron 45.3.2**，数据库依赖至 **better-sqlite3 13.2.0**。
- 更新 **ws 8.23.0**，修复恶意对端大量发送 Ping 时可能造成的内存耗尽问题。
- 更新国际化、表单、代理和图标依赖，并同步构建、测试和离线打包工具。

## 升级兼容性

**升级前请备份配置和下载文件。** 捆绑引擎使用 SQLite **schema 6**。
从旧版引擎数据库升级时，请保留完整的升级前备份；旧引擎无法打开 schema 6。
如需降级，应先停止所有引擎，再将验证过的备份恢复到单独路径。
不要通过重置或删除已升级数据库来代替恢复。

从 Motrix v1 迁移的用户应遵循
[迁移指南](https://github.com/agalwood/Motrix/blob/v2.4.2/docs/legacy-migration.zh-CN.md)，
并保留原始配置及引擎数据库备份。

## 下载与更新

桌面安装包支持 macOS 13 及以上、Windows 10 及以上和 Linux，提供原生 x64 与 ARM64
构建，不提供 32 位桌面安装包。官方 macOS 安装包必须经过签名和公证。
Windows NSIS 安装程序和 ZIP 未签名，可能触发 SmartScreen；请使用官方 Release 下载。

正式发布会将 `latest*.yml` 和 `beta*.yml` 更新源同时更新至 2.4.2。
Flatpak 安装包和 Native Host 配套程序仍单独提供下载。Snap 可用性以验证后的 Store
发布为准：先发布至 edge，再将同一组 amd64/arm64 修订依次晋级至 candidate 和 stable。

Server 镜像使用 `docker.io/motrixapp/motrix-server:2.4.2` 和
`ghcr.io/agalwood/motrix-server:2.4.2`。公开镜像通过多平台运行验证后，
`2.4`、`2`、`stable` 和 `latest` 将指向同一已验证摘要。详见
[Docker Server 指南](https://github.com/agalwood/Motrix/blob/v2.4.2/docs/docker-server.zh-CN.md)。
