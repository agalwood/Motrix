# Motrix 2.0.0

[English](https://github.com/agalwood/Motrix/blob/v2.0.0/docs/release-notes/2.0.0.md) | 简体中文

Motrix 2.0.0 是 Motrix v2 的首个正式版，使用 Electron、React 和 TypeScript
重新开发。桌面下载管理器与带 Web 界面的 Headless Server 使用同一套下载内核。

## 主要功能

- 支持 HTTP、FTP、BitTorrent 和磁力链接下载，提供文件选择、会话持久化、
  Tracker 管理和可配置的速度限制。
- 支持自定义仪表盘、任务活动图表、明暗主题、系统通知和应用内通知中心。
- 插件在沙箱中运行，使用明确的能力授权；提供应用内插件市场，以及用于文件名
  模板和 URL 解析的已签名官方插件。
- 通过 Motrix Extension 和 Native Messaging 集成浏览器；提供 `@motrix/cli`
  命令行客户端和 MDXP 协议，支持本地与远程使用。
- Headless Server 面向 Docker、NAS 和家庭服务器，提供 Web 界面，并支持远程
  CLI 客户端通过 device-code 配对。
- Windows、macOS 和 Linux 均提供原生 x64 与 ARM64 桌面安装包，捆绑
  aria2 1.37.0-motrix.19。不提供 32 位桌面安装包。

## 相比 beta.52 的变化

- 全新安装默认跟随系统语言，已有语言偏好保持不变。
- Windows 普通下载完成时，移除临时后缀不再需要对整个文件计算哈希。
  复制和插件修改后的输出仍保留内容校验，中断的重命名仍执行恢复检查。
- 更新桌面端和 Server 依赖，包括 Electron 45。窗口显示后会恢复最大化状态，
  仪表盘传输条的宽度变化增加过渡动画。

## 下载与更新通道

| 分发方式 | 架构 | 产物 |
|----------|------|------|
| macOS 13 及以上 | `arm64`、`x64` | 已签名并公证的 DMG 和 ZIP |
| Windows 10+ | `x64`、`arm64` | 未签名的 NSIS 安装程序和 ZIP |
| Linux | `x64`、`arm64` | AppImage、DEB、RPM 和 pacman |
| Flatpak 主程序 | `x86_64`、`aarch64` | 带版本号的 `.flatpak` 安装包 |
| Flatpak Native Host 配套程序 | `linux/x64`、`linux/arm64` | 带版本号的 `.tar.gz` 压缩包 |
| Docker Hub / GHCR | `linux/amd64`、`linux/arm64` | 不可变的 `2.0.0` 标签 |
| Snap Store | `amd64`、`arm64` | 同一组已验证 revision 依次晋级 edge、candidate 和 stable |

Windows 安装包未签名，可能触发 SmartScreen。请从官方 GitHub Release 下载。
x64 使用 `Motrix-Setup-2.0.0.exe`，ARM64 使用
`Motrix-Setup-2.0.0-arm64.exe`。Windows ARM 上已有的 x64 安装仍沿 x64 更新路径
升级。切换架构前请备份配置并关闭 Motrix，不要让两种架构同时使用同一份配置。

正式发布将桌面端的 `latest*.yml` 和 `beta*.yml` 更新清单一起更新到 2.0.0，
让已有的 v2 beta 安装也能升级到本版本。
Flatpak 安装包需要使用 `flatpak install --user --or-update` 手动更新，
Native Host 配套程序也需单独更新，详见
[Flatpak 指南](https://github.com/agalwood/Motrix/blob/v2.0.0/docs/flatpak.zh-CN.md)。
Snap 构建最初发布到 `latest/edge`，晋级时不重新构建。
`latest/stable` 晋级完成后，可使用 `sudo snap install motrix` 安装。

容器可使用 `docker.io/motrixapp/motrix-server:2.0.0` 或
`ghcr.io/agalwood/motrix-server:2.0.0`。只有不可变的多平台镜像通过公开运行检查后，
才会更新 `2.0`、`2`、`stable` 和 `latest` 别名。详见
[Docker Server 指南](https://github.com/agalwood/Motrix/blob/v2.0.0/docs/docker-server.zh-CN.md)。

## 从 Motrix v1 或 v2 beta 升级

Motrix v1 也使用同一稳定版更新源。接受更新前，请先确认满足上方的平台要求。
低于 macOS 13 的系统、Windows 7／8／8.1 和所有 32 位 Windows 均无法运行
本版本，请在升级操作系统或硬件前保留兼容版本。

升级前请备份配置和下载文件，并关闭旧应用。
桌面迁移助手会把选中的 v1 任务导入为暂停记录；仅导入不会启动下载或修改原文件。
复用 BitTorrent 进度需要原始元数据、原始目录和明确授权。Windows 要求使用本地
固定 NTFS 卷，并通过
[迁移指南](https://github.com/agalwood/Motrix/blob/v2.0.0/docs/legacy-migration.zh-CN.md)
中的所有权、路径和权限检查。导入的 HTTP 记录激活后会使用独立目录。

请保留引擎的 `*.pre-schema5-*.db` 备份。旧引擎无法打开升级后的数据库；
如需降级，请在独立路径中使用经过验证的备份。

## 验证范围限制

真实 Windows SMB Explorer 行为、原生 fnOS 验收和完整 Chromium Extension
下载提交流程仍不在本次发布已验证的覆盖范围内。反馈可复现问题时，请附上
操作系统、架构、安装包类型和复现步骤。
