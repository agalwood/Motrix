# Motrix 2.0.0-beta.45

[English](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.45/docs/release-notes/2.0.0-beta.45.md) | 简体中文

Motrix 2.0.0-beta.45 新增经过验证的一键 FFmpeg 安装、恢复安全范围内的 Motrix
应用链接，并可在下载完成后关闭电脑。本版本还加入匈牙利语、让 Safari 扩展
更易发现，同时修复下载、NAT 和详情抽屉相关问题。

## 主要更新

- 媒体工具现在可以在受支持的 macOS、Windows 和 Linux 目标上一键安装官方
  FFmpeg。Motrix 会先验证发布清单签名、跳转、哈希、压缩包内容、可执行文件
  架构和平台信任要求，再以原子方式启用新版本。FFmpeg 仍是由用户主动下载的
  独立组件，不会打包进应用（[#2299](https://github.com/agalwood/Motrix/pull/2299)）。
- 下载页底部新增一次性的“全部完成后关机”操作。所有下载和收尾工作结束后，
  会进入可取消的 60 秒倒计时。Web、Snap 和 Flatpak 构建不提供此功能
  （[#2284](https://github.com/agalwood/Motrix/pull/2284)）。
- 受限范围内的 `motrix://` 链接可导航到页面或预填新任务，但仍需用户明确
  提交。旧的 `mo://` 协议，以及直接控制任务或显示本地路径的链接已停用
  （[#2300](https://github.com/agalwood/Motrix/pull/2300)）。
- 界面新增匈牙利语；Integration 页面也加入单独分发的 Safari 扩展入口
  （[#2117](https://github.com/agalwood/Motrix/pull/2117)、
  [#2283](https://github.com/agalwood/Motrix/pull/2283)）。
- 浏览器提交的下载现在支持 IP 地址、localhost 和本地主机名，不再自动合成
  空的 `Authorization` 请求头，并能在跨域跳转后保留正确文件名
  （[#2282](https://github.com/agalwood/Motrix/pull/2282)、
  [#2276](https://github.com/agalwood/Motrix/pull/2276)、
  [#2295](https://github.com/agalwood/Motrix/pull/2295)）。
- 详情抽屉打开时，所有下载行都能滚动到可见区域；紧凑布局尺寸变化后也会
  及时更新。工具栏空白区域仅在紧凑布局中可拖动，展开窗口时可正常取消空搜索
  （[#2288](https://github.com/agalwood/Motrix/pull/2288)、
  [#2290](https://github.com/agalwood/Motrix/pull/2290)、
  [#2281](https://github.com/agalwood/Motrix/pull/2281)）。
- 自动端口映射现在接受合法的 Unicode 路由器描述，例如华为 AX3 的广播信息
  （[#2297](https://github.com/agalwood/Motrix/pull/2297)）。
- Electron、pnpm、签名依赖和安全锁文件已更新；准备更新时，两套依赖树均未
  报告已知漏洞（[#2287](https://github.com/agalwood/Motrix/pull/2287)）。

## 测试前须知

这是预发布软件。安装前请备份现有 Motrix 应用数据和下载文件。Motrix v1 数据的
迁移路径尚未经过验证，请勿让本 beta 使用您唯一的一份 v1 数据。

条件允许时，请使用独立的操作系统账号、设备或 Docker 数据目录并行测试 v2。

如需使用托管 FFmpeg，请打开 Settings → Integration → Media tools 并执行安装。
正在运行的插件需要重启 Motrix，才能识别新安装的托管 FFmpeg。Windows FFmpeg
构建未签名，可能显示 SmartScreen 警告；macOS 构建必须通过 Motrix 固定的签名
身份和在线公证检查。

关机操作仅生效一次。暂停、失败、排队或等待元数据的任务会阻止关机；新任务或
状态变化会取消倒计时。测试前请先保存其他应用中尚未保存的工作。

受保护的 Snap 工作流完成后，可使用 `sudo snap install motrix --edge` 安装
严格限制的构建。已跟踪 `latest/edge` 的安装应升级到同一组 beta.45 revision。

## 发布门禁通过后计划提供的下载

| 分发方式 | 架构 | 计划产物 |
|---------|------|---------|
| macOS 13 或更高版本 | `arm64`（Apple Silicon）、`x64`（Intel） | 已签名并公证的 DMG 和 ZIP |
| Windows | `x64` | 未签名 NSIS 安装程序（`.exe`）和 ZIP |
| Linux | `x64`、`arm64` | AppImage、DEB、RPM 和 pacman |
| Flatpak 主程序 | `x86_64`、`aarch64` | `Motrix-2.0.0-beta.45-<arch>.flatpak` |
| Flatpak Native Host companion | `linux/x64`、`linux/arm64` | `Motrix-Native-Host-2.0.0-beta.45-linux-<arch>.tar.gz` |
| Docker Hub / GHCR | `linux/amd64`、`linux/arm64` | 两个仓库中的不可变 `2.0.0-beta.45` 标签 |
| Snap Store | `amd64`、`arm64` | `latest/edge` 上的已验证构建集 |

所有容器门禁通过后，可使用以下带版本镜像：
`docker.io/motrixapp/motrix-server:2.0.0-beta.45` 和
`ghcr.io/agalwood/motrix-server:2.0.0-beta.45`。存储、网络与升级说明请参阅
[Docker Server 部署指南](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.45/docs/docker-server.zh-CN.md)。

## 分发说明

- Flatpak 主程序使用应用 ID `app.motrix.native` 和 `beta` 分支。每次升级需
  下载新包并执行 `flatpak install --user --or-update`；这些单文件包没有配置
  Motrix 更新 remote。使用浏览器集成时，还需单独更新 Native Host companion。
  详见 [Flatpak 指南](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.45/docs/flatpak.zh-CN.md)。
- AppImage 桌面集成仍需主动启用。浏览器冷启动需要单独启用 Native Messaging
  host 并注册 AppImage 路径；使用已保存配对重连还需要兼容的配套 Extension。
- 不提供 Windows `arm64` 和所有 32 位安装包。Windows 安装包未签名，可能触发
  Windows SmartScreen 警告，请仅从已发布的官方 GitHub 预发布版下载。
- Beta 容器标签不可变，也不会更新 `latest`、`stable` 或其他稳定通道浮动标签。
- Snap 安装包使用严格限制。已批准的 `personal-files` interface 仅用于为支持的
  浏览器注册 Native Messaging host manifest。Beta 发布只会更新 `latest/edge`。
