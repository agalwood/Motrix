# Motrix 2.4.4

[English](https://github.com/agalwood/Motrix/blob/main/docs/release-notes/2.4.4.md) | 简体中文

## 相比 2.4.3 的变化

- 修复大量文件的 BT 种子添加时引擎卡住的问题（#2536）。捆绑的 aria2 **1.37.0-motrix.25** 按顺序追加文件映射，Motrix 将连续选择压缩成区间。添加失败会在对话框显示原因；清理结果不确定时保留原任务标识，在重启后核对，避免残留零字节排队任务。
- 升级到 **MDXP 0.10.0**，使用 SDK 提供的下载交接方法和校验规则。
- 桌面端现可与已配对的扩展协商直链下载交接。启动桌面端前设置 `MOTRIX_DOWNLOAD_HANDOFF=1` 即可接受新的交接；关闭后仍可查询和恢复先前已准备或已提交的操作。
- 桌面任务管理器先持久化任务，再交给引擎。扩展丢失回执后可以重连并找回原任务 ID。浏览器扩展 **0.1.24** 继续通过原有接口提交下载。

## 升级兼容性

**升级前请备份配置和下载文件。** 捆绑引擎使用 SQLite **schema 6**。
从旧版引擎数据库升级时，请保留完整的升级前备份；旧引擎无法打开 schema 6。
如需降级，应先停止所有引擎，再将验证过的备份恢复到单独路径。
不要通过重置或删除已升级数据库来代替恢复。

从 Motrix v1 迁移的用户应遵循
[迁移指南](https://github.com/agalwood/Motrix/blob/v2.4.4/docs/legacy-migration.zh-CN.md)，
并保留原始配置及引擎数据库备份。

## 下载与更新

桌面安装包支持 macOS 13 及以上、Windows 10 及以上和 Linux，提供原生 x64 与 ARM64
构建，不提供 32 位桌面安装包。官方 macOS 安装包必须经过签名和公证。
Windows NSIS 安装程序和 ZIP 未签名，可能触发 SmartScreen；请使用官方 Release 下载。

正式发布会将 `latest*.yml` 和 `beta*.yml` 更新源同时更新至 2.4.4。
Flatpak 安装包和 Native Host 配套程序仍单独提供下载。Snap 可用性以验证后的 Store
发布为准：先发布至 edge，再将同一组 amd64/arm64 修订依次晋级至 candidate 和 stable。

Server 镜像使用 `docker.io/motrixapp/motrix-server:2.4.4` 和
`ghcr.io/agalwood/motrix-server:2.4.4`。公开镜像通过多平台运行验证后，
`2.4`、`2`、`stable` 和 `latest` 将指向同一已验证摘要。详见
[Docker Server 指南](https://github.com/agalwood/Motrix/blob/v2.4.4/docs/docker-server.zh-CN.md)。
