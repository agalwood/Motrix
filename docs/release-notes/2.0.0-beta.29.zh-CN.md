# Motrix 2.0.0-beta.29

[English](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.29/docs/release-notes/2.0.0-beta.29.md) | 简体中文

Motrix 2.0.0-beta.29 引入了安全的 Motrix Extension 控制平面，补齐了
Desktop 与 Server 的应用 API，加入可持久化的插件 hook runtime，并更新
内置 aria2 引擎。只有在所有受保护发布门禁通过后，本版本才适合
公开分发。

## 主要改进

- [Motrix Extension](https://github.com/motrixapp/motrix-extension) 现可通过
  Native Messaging 和 MBP1 与桌面应用配对。经过审查的协议使用短配对码、
  加密 WebSocket envelope、可持久化凭据、有界重试与显式撤销。Chrome、
  Edge 和 Firefox 的官方身份已在 manifest、测试向量与 runtime 策略中
  对齐；开发构建的 Native Messaging host 也会跟随独立的开发数据目录
  （[#2021](https://github.com/agalwood/Motrix/pull/2021)）。
- Headless Server 可显式开启 Motrix Extension，并通过配置的 WS/WSS 地址
  完成配对。远程入口在 operator 主动开启前保持关闭，并由接入、origin、
  route、进程所有权与 TLS 策略共同约束；发布流程还包含兼容性、威胁证据、
  集成与 soak 检查
  （[#2033](https://github.com/agalwood/Motrix/pull/2033)）。
- Desktop 与 Server 现共用 host-neutral 的应用 command 和 query 实现。浏览器
  UI 新增多 torrent 解析与队列，bridge、插件、文件选择、代理和任务管理
  在两个 host 间保持一致。Server operator 还可选择开启带认证的对外 aria2
  RPC，loopback 仍是默认选项
  （[#2008](https://github.com/agalwood/Motrix/pull/2008)、
  [#2037](https://github.com/agalwood/Motrix/pull/2037)）。
- 插件现可运行强类型的下载前置与后置 hook，支持 staged effect、可持久化
  后处理、启动恢复和抗崩溃收尾。Desktop 与 Server 使用同一套 runtime，
  跨平台收尾工具则在 Windows 和 Unix 上保持必要的文件系统操作顺序
  （[#2038](https://github.com/agalwood/Motrix/pull/2038)）。
- 内置 aria2 升级到 `1.37.0-motrix.12`，全部受支持 archive 与 binary 均按
  SHA-256 锁定。WebSocket RPC 启动与并发响应契约现有端到端测试覆盖，
  少量原生 RPC 诊断会进入应用日志，trust store 处理也更稳健
  （[#2032](https://github.com/agalwood/Motrix/pull/2032)）。
- Native Messaging 与 Flatpak 集成进一步加固：开发配置限于 owner 读写，
  caller 和文件系统验证更严格，broker 进程受到时限约束，companion 使用
  原子安装与更安全的清理。Flatpak companion 仍是唯一的 host-side 进程，
  并继续通过 broker 边界访问沙箱中的 bridge。
- 代理下的重定向下载现会保留预期文件名，Tracker 同步遵循当前代理，
  系统代理探测在隔离 session 中运行，全局连接选项会传给新建任务，FFmpeg
  在 media mux 前即时解析
  （[#2006](https://github.com/agalwood/Motrix/pull/2006)、
  [#2013](https://github.com/agalwood/Motrix/pull/2013)、
  [#2019](https://github.com/agalwood/Motrix/pull/2019)、
  [#2022](https://github.com/agalwood/Motrix/pull/2022)）。
- 桌面端修复包括过期的默认保存目录、不可用的 Downloads 路径、Windows 快捷方式与
  最大化窗口恢复、框选稳定性、更清晰的配对提示、统一的“设置”文案、更宽的
  peer 地址列，以及完成或失败后对临时 media segment 任务的清理
  （[#2014](https://github.com/agalwood/Motrix/pull/2014)、
  [#2016](https://github.com/agalwood/Motrix/pull/2016)、
  [#2023](https://github.com/agalwood/Motrix/pull/2023)、
  [#2030](https://github.com/agalwood/Motrix/pull/2030)、
  [#2036](https://github.com/agalwood/Motrix/pull/2036)、
  [#2039](https://github.com/agalwood/Motrix/issues/2039)、
  [#2041](https://github.com/agalwood/Motrix/pull/2041)）。

## 测试前须知

这是预发布软件。安装前请备份现有 Motrix 应用数据和下载文件。Motrix v1 数据的
迁移路径尚未经过验证，请勿让本 beta 使用您唯一的一份 v1 数据。

条件允许时，请使用独立的操作系统账号、设备或 Docker 数据目录并行测试 v2。
请重点检查 Motrix Extension 首次配对与重连、TLS 反向代理后的远程扩展配对、
重启或收尾中断前后的插件 hook、浏览器端 torrent 新建、并发 aria2 RPC 流量、
代理重定向，以及对应平台的 Native Messaging 注册。

受保护发布完成后，Snap 测试者可使用
`sudo snap install motrix --edge` 安装严格限制的构建。已跟踪
`latest/edge` 的安装应升级到同一组 beta.29 revision。

## 分发说明

- AppImage 桌面集成需要用户主动启用，且只会写入当前用户的 XDG 数据目录。由于
  Native Messaging host 在挂载镜像之外没有稳定路径，浏览器扩展暂时无法向
  AppImage 安装包转交下载任务。
- Flatpak 单独验证，不由 release tag 发布；GitHub 预发布版会包含它的
  Native Host companion 压缩包。
- 不提供 Windows `arm64` 和所有 32 位安装包。
- Windows 安装包未签名，可能触发 Windows SmartScreen 警告。请仅从已发布的
  官方 GitHub 预发布版下载。
- Beta 容器标签不可变，也不会更新 `latest`、`stable` 或其他稳定通道
  浮动标签。
- Snap 安装包使用严格限制。已批准的 `personal-files` interface 仅用于为支持的
  浏览器注册 Native Messaging host manifest。Beta 发布只会更新
  `latest/edge`，不会把构建晋级到 `candidate` 或 `stable`。
