# Motrix 2.0.0-beta.52

English | [简体中文](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.52/docs/release-notes/2.0.0-beta.52.zh-CN.md)

Motrix 2.0.0-beta.52 adds native Windows ARM64 desktop packages, including
aria2 1.37.0-motrix.19, the filesystem helper, and the browser Native Host.

## Highlights

- Windows ARM64 computers can use a native NSIS installer or portable ZIP.
  Electron, SQLite, aria2, and both native helpers use the ARM64 build.
  The new engine is published separately as
  [aria2 1.37.0-motrix.19](https://github.com/motrixapp/aria2/releases/tag/v1.37.0-motrix.19).
- Windows x64 download names stay unchanged. ARM64 installers and ZIPs have
  an explicit `arm64` suffix. Both architectures share the Windows update
  channel, which selects the installer for the running app's architecture.
- Native Windows release checks cover the packaged application, SQLite,
  native helpers, and aria2 WebSocket communication. Engine release checks
  also exercise HTTPS certificate trust, long paths, task cookies, and legacy
  checkpoint recovery on Windows ARM64.

## Choosing a Windows package

| Computer / app architecture | Installer | Portable archive |
|-----------------------------|-----------|------------------|
| x64 | `Motrix-Setup-2.0.0-beta.52.exe` | `Motrix-2.0.0-beta.52-win.zip` |
| ARM64 | `Motrix-Setup-2.0.0-beta.52-arm64.exe` | `Motrix-2.0.0-beta.52-win-arm64.zip` |

An existing x64 installation running under Windows ARM emulation stays on the
x64 update path. To switch to the native build, back up your profile, close
Motrix, and install the ARM64 package. Do not run both architectures against the
same profile at the same time.

Windows packages are unsigned and may trigger SmartScreen. Download from the
official GitHub prerelease. No 32-bit desktop packages are provided.

## Planned downloads after release gates pass

| Distribution | Architectures | Planned output |
|--------------|---------------|----------------|
| macOS 13 or later | `arm64`, `x64` | Signed and notarized DMG and ZIP |
| Windows | `x64`, `arm64` | Unsigned NSIS installer and ZIP |
| Linux | `x64`, `arm64` | AppImage, DEB, RPM, and pacman |
| Flatpak application | `x86_64`, `aarch64` | Versioned `.flatpak` bundle |
| Flatpak Native Host companion | `linux/x64`, `linux/arm64` | Versioned `.tar.gz` archive |
| Docker Hub / GHCR | `linux/amd64`, `linux/arm64` | Immutable `2.0.0-beta.52` tag |
| Snap Store | `amd64`, `arm64` | Verified build set on `latest/edge` |

After every container gate passes, use
`docker.io/motrixapp/motrix-server:2.0.0-beta.52` or
`ghcr.io/agalwood/motrix-server:2.0.0-beta.52`. See the
[Docker Server guide](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.52/docs/docker-server.md).
Beta publication does not update stable container aliases.

Snap users can install with `sudo snap install motrix --edge`. Flatpak bundles
require manual updates with `flatpak install --user --or-update`; update the
Native Host companion separately. See the
[Flatpak guide](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.52/docs/flatpak.md).

## Before testing

Back up the profile and downloads before upgrading. Legacy migration still
imports paused records and requires explicit authorization before reusing
BitTorrent data. Windows recovery requires a local fixed NTFS volume and the
ownership, path, and permission checks described in the
[migration guide](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.52/docs/legacy-migration.md).
Retain the engine's pre-schema5 database backup.

Real Windows SMB Explorer behavior, native fnOS acceptance, and the complete
Chromium Extension download-submission flow remain outside this release's
verified coverage. Report reproducible issues with your OS, architecture,
package type, and reproduction steps.
