# Motrix 2.3.0

[English](https://github.com/agalwood/Motrix/blob/main/docs/release-notes/2.3.0.md) | 简体中文

Motrix 2.3.0 更新应用图标，恢复网盘目录下载，并完善 Motrix Server 的媒体工具和设置。
本版还引入飞牛 fnOS 原生集成，并通过独立流程验证和发布安装包。

## 相比 2.2.1 的变化

- 更新桌面安装包、Web UI 和 fnOS 的应用图标，加入原生 macOS 图标资源，
  并更新 Windows 安装程序插图。
- 随 **aria2 1.37.0-motrix.23** 恢复网盘目录下载，并改善目录元数据重试后的恢复行为。
- Server 用户可在媒体工具中下载并验证官方 FFmpeg，Web UI 会显示进度和错误。
  验证后的文件保存在数据卷中，媒体能力无需重启 Server 即可刷新。
- 修复 Web UI 目录设置和应用内通知设置的操作。新增 Server 更新检查，支持选择
  stable/beta 通道；安装 Server 更新仍需手动更新部署。
- 根据已签名的发布元数据验证旧版 macOS FFmpeg 安装后再信任它，
  并改善媒体工具中的检测与修复反馈。
- 取消新建下载对话框时，保持原本隐藏的主窗口隐藏。
- 新增 x64 和 ARM64 飞牛 fnOS 原生打包，支持绑定账号的 CLI 和浏览器扩展授权、
  系统目录授权及服务生命周期检查。首版采用管理员共享实例：管理员共享任务和设置，
  普通用户无法访问；不提供按用户隔离任务的能力。

Electron 保持为 **45.2.1**。原生 fnOS 安装包由
[受保护的 fnOS 发布流程](https://github.com/agalwood/Motrix/actions/workflows/fnos-publish.yml)
单独发布，前提是正式发布成功，且两种架构均通过原生打包和生命周期检查。
Release 附件名为 `Motrix-2.3.0-fnos-x64.fpk` 和
`Motrix-2.3.0-fnos-arm64.fpk`，各附带一个 `.sha256` 校验文件。
请下载与 NAS 架构匹配的安装包。这是直接分发安装包，不代表应用商店上架。
自动化生命周期检查使用模拟的 fnOS 文件 API，真实设备兼容性仍需安装验证。
详见 [fnOS 打包指南](https://github.com/agalwood/Motrix/blob/main/packaging/fnos/README.md)。

## 升级兼容性

**升级前请备份配置和下载文件。** 捆绑引擎使用 SQLite **schema 6**。
从旧版引擎数据库升级时，请保留完整的升级前备份；旧引擎无法打开 schema 6。
如需降级，应先停止所有引擎，再将验证过的备份恢复到单独路径。
不要通过重置或删除已升级数据库来代替恢复。

从 Motrix v1 迁移的用户应遵循
[迁移指南](https://github.com/agalwood/Motrix/blob/v2.3.0/docs/legacy-migration.zh-CN.md)，
并保留原始配置及引擎数据库备份。

## 下载与更新

桌面安装包支持 macOS 13 及以上、Windows 10 及以上和 Linux，提供原生 x64 与 ARM64
构建，不提供 32 位桌面安装包。官方 macOS 安装包必须经过签名和公证。
Windows NSIS 安装程序和 ZIP 未签名，可能触发 SmartScreen；请使用官方 Release 下载。

正式发布会将 `latest*.yml` 和 `beta*.yml` 更新源同时更新至 2.3.0。
Flatpak 安装包和 Native Host 配套程序仍单独提供下载。Snap 可用性以验证后的 Store
发布为准：先发布至 edge，再将同一组 amd64/arm64 修订依次晋级至 candidate 和 stable。

Server 镜像使用 `docker.io/motrixapp/motrix-server:2.3.0` 和
`ghcr.io/agalwood/motrix-server:2.3.0`。公开镜像通过多平台运行验证后，
`2.3`、`2`、`stable` 和 `latest` 将指向同一已验证摘要。详见
[Docker Server 指南](https://github.com/agalwood/Motrix/blob/v2.3.0/docs/docker-server.zh-CN.md)。
