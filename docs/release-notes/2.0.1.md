# Motrix 2.0.1

English | [简体中文](https://github.com/agalwood/Motrix/blob/v2.0.1/docs/release-notes/2.0.1.zh-CN.md)

Motrix 2.0.1 is a maintenance release for the desktop app and headless Server.
It improves download recovery, desktop stability, and memory use, and updates
application and packaging dependencies.

## Changes since 2.0.0

- Improves HTTP resume metadata checks and preserves resource identity across
  cross-origin redirects, including redirects back to the original host.
  Failed verification now reports diagnostic reasons without exposing secrets;
  unverifiable partial files remain protected from unsafe resume.
- Allows verified legacy HTTP downloads to resume through the Migration
  Assistant when the original partial file and checkpoint pass the supported
  recovery checks. Importing a task still leaves it paused until activation.
- Adds recovery after repeated graphics crashes, with hardware acceleration
  controls in Appearance settings.
- Bounds cached migration data and plugin logs, releases idle runtime
  resources, and improves tray renderer cleanup to reduce memory use.
- Bundles aria2 **1.37.0-motrix.21**, including DNS timer recovery for the
  select event loop. Managed aria2 processes now stop when their desktop or
  Server host exits unexpectedly.
- Uses the package name `motrix` consistently for native Linux packages.
- Updates electron-builder, electron-updater, React Hook Form, i18next,
  react-i18next, and Biome. Plugin test fixtures now share SDK 2.2.0, and
  formatting no longer rewrites Markdown documents or YAML configuration.

## Downloads and updates

Desktop packages support macOS 13 or later, Windows 10 or later, and Linux,
with native x64 and ARM64 builds. No 32-bit desktop packages are provided.
macOS DMG and ZIP packages are signed and notarized. Windows NSIS installers
and ZIP archives are unsigned and may trigger SmartScreen; download them from
the official GitHub Release.

The stable publication updates both `latest*.yml` and `beta*.yml` feeds to
2.0.1. Flatpak bundles and their Native Host companions remain separate
downloads; see the [Flatpak guide](https://github.com/agalwood/Motrix/blob/v2.0.1/docs/flatpak.md).
Snap builds are first published to `latest/edge`, then the same verified
amd64 and arm64 revisions are promoted through candidate to stable.

Server images use the immutable `2.0.1` tag on
`docker.io/motrixapp/motrix-server` and `ghcr.io/agalwood/motrix-server`.
The `2.0`, `2`, `stable`, and `latest` aliases are promoted only after the
multi-platform images pass public runtime verification.

Back up your profile and download files before upgrading. Users migrating
from Motrix v1 should follow the
[migration guide](https://github.com/agalwood/Motrix/blob/v2.0.1/docs/legacy-migration.md)
and retain their original profile and engine database backups.

## Known verification limits

The Windows HTTP resume preflight failure reported in
[#2426](https://github.com/agalwood/Motrix/issues/2426) remains under
investigation; the verification and diagnostic improvements in this release
do not establish that every reported environment is fixed.
