# Motrix 2.4.6

[English](https://github.com/agalwood/Motrix/blob/main/docs/release-notes/2.4.6.md) | 简体中文

## 相比 2.4.5 的变化

- **内置引擎升级至 aria2 1.37.0-motrix.26（#2551、#2556）**：在源链接哈希、输出路径、总长度及强校验器（`ETag` / `Last-Modified`）一致且未发生 HTTPS 降级的前提下，允许动态 CDN/镜像重定向目标并发续传，恢复 HTTP 多连接满速下载。
- **修复大文件无总大小与无法续传（#2540、#2554）**：全局关闭 `http-accept-gzip` 并将元数据探测统一对齐为 `identity` 编码，恢复大文件的 `Content-Length`、进度百分比、分片并发与断点续传。
- **macOS SMB 共享盘落盘兼容（#2549、#2555）**：在 macOS `smbfs` 挂载下支持 `F_FULLFSYNC` 降级到 `fsync`（`remote_acknowledged`），并兼容保留文件跨 `renameat` 时的合成 `st_ino` 变化，修复下载到 SMB 共享盘最终落盘失败的问题。
- **直连磁力链接保存目录修复（#2552、#2553）**：直连磁力任务直接保留在目标下载目录中，不再额外嵌套一层哈希值子文件夹，并自动收敛元数据 `followedBy` 切换状态。
- **BitTorrent 默认监听端口迁移（#2462、#2558）**：将旧默认 BT / DHT 监听端口从 `6881` 一次性迁移至 `21301` / `26701`（保留用户自定义端口），并在端口绑定冲突时显示明确的 `BtPortBindFailed` 诊断提示。
- **增强 aria2 启动探针抗抖动能力（#2517、#2559）**：为 `aria2c --version` 启动探针增加针对瞬态文件锁/权限/超时（`EBUSY`、`EACCES`、`ETIMEDOUT` 等）的有界退避重试，避免 Windows 实时防毒扫描短暂锁文件导致误报引擎二进制缺失。
- **跨源签名重定向断点续传校验（#2426、#2488、#2560）**：校验跨源重定向资源身份时忽略短期签名与过期令牌查询参数（涵盖 GitHub Releases / Azure SAS、AWS S3 / R2、GCS、阿里云 OSS、腾讯云 COS 等），同时仍严格拒绝源站、路径或内容参数变更。
- **运行期日志轮转与临时媒体目录清理（#2532、#2561）**：`motrix.log` 支持运行期达到 5 MiB 自动轮转（仅保留 1 份 `.1` 备份），并在启动时清理 `%TEMP%/motrix-media` 中残留的孤儿 `motrix-media-*` 目录，防止长期占用系统盘空间。
- **支持记住或自定义启动下载视图（#2543）**：可在设置中选择记住上次离开的下载视图或固定默认打开视图。

## 升级兼容性

**升级前请备份配置和下载文件。** 捆绑引擎使用 SQLite **schema 6**。
从旧版引擎数据库升级时，请保留完整的升级前备份；旧引擎无法打开 schema 6。
如需降级，应先停止所有引擎，再将验证过的备份恢复到单独路径。
不要通过重置或删除已升级数据库来代替恢复。

从 Motrix v1 迁移的用户应遵循
[迁移指南](https://github.com/agalwood/Motrix/blob/v2.4.6/docs/legacy-migration.zh-CN.md)，
并保留原始配置及引擎数据库备份。

## 下载与更新

桌面安装包支持 macOS 13 及以上、Windows 10 及以上和 Linux，提供原生 x64 与 ARM64
构建，不提供 32 位桌面安装包。官方 macOS 安装包必须经过签名和公证。
Windows NSIS 安装程序和 ZIP 未签名，可能触发 SmartScreen；请使用官方 Release 下载。

正式发布会将 `latest*.yml` 和 `beta*.yml` 更新源同时更新至 2.4.6。
Flatpak 安装包和 Native Host 配套程序仍单独提供下载。Snap 可用性以验证后的 Store
发布为准：先发布至 edge，再将同一组 amd64/arm64 修订依次晋级至 candidate 和 stable。

Server 镜像使用 `docker.io/motrixapp/motrix-server:2.4.6` 和
`ghcr.io/agalwood/motrix-server:2.4.6`。公开镜像通过多平台运行验证后，
`2.4`、`2`、`stable` 和 `latest` 将指向同一已验证摘要。详见
[Docker Server 指南](https://github.com/agalwood/Motrix/blob/v2.4.6/docs/docker-server.zh-CN.md)。
