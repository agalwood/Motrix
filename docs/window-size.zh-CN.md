# 主窗口尺寸

[English](window-size.md)

Motrix 主窗口的默认最小尺寸为 914 × 672 逻辑像素。使用平铺窗口管理器或需要紧凑的桌面布局时，
可以在 Motrix 用户数据目录内的 `settings.json` 中，通过 `app` 对象覆盖这两个限制。

1. 打开**设置 → 高级**，在**配置文件**一栏查看当前使用的 `settings.json` 路径，点击**打开所在目录**找到文件。
2. 完全退出 Motrix，包括托盘或菜单栏中的后台进程，然后再编辑配置。
3. 在已有的 `app` 对象中添加或修改以下两个字段，保留其他设置：

   ```json
   {
     "app": {
       "mainWindowMinWidth": 320,
       "mainWindowMinHeight": 240
     }
   }
   ```

4. 保存文件并重新启动 Motrix。此时可以将主窗口缩小到配置的尺寸；修改限制本身不会立即改变窗口大小。

每个值均为 0 到 2147483647 之间的整数。`0` 表示取消 Motrix 对应方向的最小尺寸限制，
但操作系统或窗口管理器仍可能施加自己的限制。字段缺失或数值非法时，宽度和高度分别回退至 914 和 672。
删除这两个字段即可恢复默认限制。

这两个选项仅用于桌面版，暂不提供设置界面入口。更新应用或修改其他设置时会保留它们。
新建任务和首次设置窗口维持原有尺寸。恢复主窗口上次保存的大小时，Motrix 会遵循当前配置的最小尺寸。

低于默认最小尺寸的布局尚未全面适配，部分内容可能被截断，控件也可能比较拥挤。遇到这种情况时请适当放大窗口。

如果编辑后文件无法解析为设置对象，Motrix 会先将原文件备份到同一目录，命名为
`settings.json.corrupt-<timestamp>-<id>.bak`，然后生成默认配置。如果无法创建备份，
会停止恢复，不覆盖原文件。权限或磁盘读取错误同样会中止加载，而不会重置设置。
单个字段值非法时仍只回退该字段，不会重置整个配置文件。
