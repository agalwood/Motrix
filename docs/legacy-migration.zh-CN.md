# 迁移旧版 Motrix 下载

桌面端迁移助手会将选中的 Motrix v1 任务导入为暂停记录。请先备份旧配置和下载
文件，关闭旧版应用，并核对待导入的任务。导入记录不会开始传输或修改原文件。

## 恢复 BitTorrent 下载

按提示提供原始 torrent 元数据，确认原下载目录，再明确激活任务。Motrix 会保留
原始文件选择。引擎先导入 `.aria2` checkpoint，再使用已授权元数据的持久化备份
创建暂停任务；应用验证绑定后才请求恢复下载。已有分片会在传输前经过校验。

此功能要求运行中的引擎报告 `SQLite3-Persistence`、`LegacyCheckpointImportV1`
和 `LegacyTorrentMetadataV1` 三项能力。缺少这些能力的旧版或自定义引擎不能激活
已导入的进度。Motrix 不会回退到重启后可能丢失已授权元数据的普通 torrent 上传。

## Windows 下载目录

Windows 进度导入要求文件位于本地固定 NTFS 卷。下载文件和元数据备份必须归运行
Motrix 的账户所有，且除 SYSTEM 和 Administrators 外，不能向其他用户授予写入
权限。Motrix 不会改写下载文件的权限。激活前请关闭正在写入这些文件的其他程序。

支持 Unicode 文件名和长路径。网络共享、FAT/exFAT 卷、junction、符号链接、云盘
reparse point、硬链接文件、备用数据流和别名路径会被拒绝。请使用原始规范目录；
移动文件或改变文件身份后，需要作为独立下载处理。

## HTTP 下载与恢复

导入的 HTTP 记录在明确激活后，会下载到独立目录。历史 checkpoint 本身无法证明
远端对象没有变化，因此迁移助手不会在原位置复用历史 HTTP 数据。

重启后，已授权的旧版 BitTorrent 任务仍以暂停状态恢复。请核对状态后明确恢复。
下载文件或元数据备份被替换、修改时，恢复授权会失效；放回旧文件也不会重新激活
已失效的授权。激活响应丢失时，Motrix 会核对已保存的 token 和 GID，避免盲目创建
重复任务。

升级旧数据库时，请保留引擎的 `*.pre-schema5-*.db` 备份。备份记录的是升级前状态。
旧引擎无法打开新 schema；如需降级，请停止所有引擎，将经过验证的备份恢复到独立
路径。已发布的引擎和应用安装包保持不变，功能支持取决于所安装版本捆绑的引擎。
