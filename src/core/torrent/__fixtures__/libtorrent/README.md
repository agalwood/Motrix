# Integration metadata fixtures

Unmodified `v2.torrent` and `v2_only.torrent` from `arvidn/libtorrent` tag
v2.0.11 (commit `9d7443f`); the second filename uses a hyphen here.
BSD-3-Clause copyright and terms are retained in `LICENSE`.

These two metadata files verify that Motrix accepts hybrid metadata through its
v1 engine projection and rejects pure v2. Payload files are not included.
The full protocol conformance corpus belongs to the independent
`@motrix/torrent` package project.
